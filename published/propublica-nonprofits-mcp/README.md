# Nonprofit Explorer

US nonprofit data: search organisations and read their IRS filings.

Keyless — no signup, no API key, no environment variables.

## Install

```bash
npx -y @mrfentmen/propublica-nonprofits-mcp
```

## Tools

| Tool | What it does |
|---|---|
| `search_organizations` | Search US nonprofits by name |
| `search_by_state` | Nonprofits registered in a US state |
| `organization` | Full nonprofit record by EIN |
| `filings` | IRS filings for a nonprofit |
| `financials` | Latest reported revenue, expenses and assets |

## Data source

ProPublica Nonprofit Explorer API
