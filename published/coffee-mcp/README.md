# coffee-mcp

Coffee drink encyclopedia from SampleAPIs. Hot and iced drinks with ingredients and descriptions.

This file is self contained. It reads public data only and never writes to the machine. All output is bounded and honest about what could not be fetched.

## Tools


* `hot`  Hot coffee drinks.
* `iced`  Iced coffee drinks.
* `search`  Search drinks by keyword.

## Usage

```bash
npm install
npm run build
node dist/index.js
```
