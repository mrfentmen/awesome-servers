# clerk-mcp

Query the Clerk Backend API (secret key; set CLERK_SECRET_KEY, Bearer): users, user details.

## Tools

- `list_users` — Clerk users, one page at a time, with email and id.
- `get_user` — One Clerk user by id, with profile and metadata.
