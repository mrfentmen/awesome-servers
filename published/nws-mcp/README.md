# nws-mcp

National Weather Service: forecasts, hourly forecasts, active alerts, station observations, nearby stations.

## Tools

- `forecast`
- `hourly_forecast`
- `active_alerts`
- `latest_observation`
- `nearby_stations`
- `point_metadata`

## Run

```bash
npm install && npm run build
npx nws-mcp
```

No key required. Keyless public API.
