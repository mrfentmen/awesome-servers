# Art Institute of Chicago

Art collection data: search artworks, fetch objects and artist records.

Keyless — no signup, no API key, no environment variables.

## Install

```bash
npx -y @mrfentmen/artic-mcp
```

## Tools

| Tool | What it does |
|---|---|
| `search_artworks` | Search the Art Institute collection |
| `artwork` | Full record for one artwork |
| `artist_search` | Search artists represented in the collection |
| `artist` | Artist biography and dates |
| `artwork_image_url` | IIIF image URL for an artwork |

## Data source

Art Institute of Chicago API
