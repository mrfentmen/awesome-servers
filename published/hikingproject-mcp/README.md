# hikingproject-mcp

Hiking Project trails: nearby search with difficulty, ratings, elevation; lookup by id.

## Setup

```bash
export HIKINGPROJECT_API_KEY=...
```

## Tools

- `get_trails` — Hiking Project trails near coordinates with difficulty, stars, ascent and conditions.
- `get_trail_by_id` — Full Hiking Project trail record by id.

Part of [awesome-mcps](https://github.com/mrfentmen/awesome-mcps).
