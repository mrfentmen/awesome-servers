# Open Library

Book data from Open Library: search, works, authors and editions.

Keyless — no signup, no API key, no environment variables.

## Install

```bash
npx -y @mrfentmen/openlibrary-mcp
```

## Tools

| Tool | What it does |
|---|---|
| `search_books` | Search books by title, author or subject |
| `work` | Work record: description, subjects and first publication |
| `author` | Author record: name, dates and biography |
| `isbn_lookup` | Find a book edition by ISBN |
| `subject` | Top works for a subject |

## Data source

Open Library API
