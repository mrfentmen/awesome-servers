# stormglass-mcp

Stormglass marine weather: point forecasts, elevation, tides. Needs key.

## Setup

```bash
export STORMGLASS_API_KEY=...
```

## Tools

- `get_weather` — Hourly marine weather for coordinates from multiple sources.
- `get_elevation` — Seabed/land elevation for a coordinate.
- `get_tides` — High/low tide extremes near a coordinate.

Part of [awesome-mcps](https://github.com/mrfentmen/awesome-mcps).
