# rxnorm-mcp

RxNorm drug concepts: lookup, normalisation, properties, package NDCs, interaction checks, spelling suggestions.

## Tools

- `drug_lookup`
- `normalize_name`
- `drug_properties`
- `package_ndcs`
- `related_concepts`
- `spelling_suggestions`

## Run

```bash
npm install && npm run build
npx rxnorm-mcp
```

No key required. Keyless public API.
