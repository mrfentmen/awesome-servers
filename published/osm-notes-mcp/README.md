# osm-notes-mcp

OpenStreetMap notes: browse by area or radius, search text, read threads, count open versus resolved.

## Tools

- `notes_in_bbox`
- `notes_near`
- `search_notes`
- `note_detail`
- `note_comments`
- `notes_stats`

## Run

```bash
npm install && npm run build
npx osm-notes-mcp
```

No key required. Keyless public API.
