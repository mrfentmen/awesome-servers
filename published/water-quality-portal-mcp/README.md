# Water Quality Portal

US water monitoring stations and sample results from USGS and EPA.

Keyless — no signup, no API key, no environment variables.

## Install

```bash
npx -y @mrfentmen/water-quality-portal-mcp
```

## Tools

| Tool | What it does |
|---|---|
| `stations_near` | Water monitoring stations near a coordinate |
| `station_detail` | Details for one monitoring station |
| `results_by_site` | Water sample results at one station |
| `results_by_characteristic` | Results for one measured characteristic at a station |
| `activities_by_site` | Sampling activities recorded at a station |

## Data source

Water Quality Portal API
