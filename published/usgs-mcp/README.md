# Usgs

Use this MCP server to live earthquake data from the USGS. Latest quakes, magnitudes, locations, and depth.

## Quick start

```bash
npm install
npm run build
node dist/index.js
```

The server uses stdio, so it can be connected to Claude Desktop, Cursor, VS Code, MCP Inspector, or another compatible MCP client.

## Tools at a glance

- `latest_quakes`: Latest earthquakes from the USGS feed.
- `query_quakes`: Query earthquakes by magnitude, count, and start time.

## Limits and privacy

This project is intentionally narrow. It should be treated as a practical helper, not a complete certification or security audit. Check the implementation and the returned data before using it with sensitive material. No credentials are required unless the project explicitly says otherwise.

## Try it

After building, connect the server through your MCP client. The repository root also contains `smoke-test.mjs` for projects covered by the shared harness. A typical tool call starts with `latest_quakes`.
