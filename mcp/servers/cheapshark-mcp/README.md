# CheapShark

Game price data: current deals, store list and price history by game.

Keyless — no signup, no API key, no environment variables.

## Install

```bash
npx -y @mrfentmen/cheapshark-mcp
```

## Tools

| Tool | What it does |
|---|---|
| `deals` | Current game deals, cheapest first |
| `stores` | Game stores CheapShark tracks |
| `game_search` | Find a game by title |
| `game_prices` | Every store price for one game |
| `store_deals` | Best deals at one store |

## Data source

CheapShark API
