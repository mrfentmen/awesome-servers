# Deezer

Music catalogue search: tracks, artists, albums and charts.

Keyless — no signup, no API key, no environment variables.

## Install

```bash
npx -y @mrfentmen/deezer-mcp
```

## Tools

| Tool | What it does |
|---|---|
| `search` | Search tracks, artists or albums on Deezer |
| `artist` | Deezer artist profile |
| `album` | Album details with its track list |
| `track` | Track details including BPM and duration |
| `artist_top_tracks` | An artist's most popular tracks |
| `chart_tracks` | Current Deezer top tracks chart |

## Data source

Deezer API
