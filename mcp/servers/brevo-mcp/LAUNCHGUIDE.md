## Description
MCP server for Brevo: account, contacts, email reports. Needs a free API key. Published from a private commercial monorepo. Not affiliated with or endorsed by Brevo.

## Setup Requirements
- `BREVO_API_KEY` (required): set in your MCP client config before use.

## Category
Marketing & Social

## Features

- Account info: Brevo account with plan and credits.
- List contacts: Brevo contacts with blacklist flags.
- Email reports: Aggregate sends, deliveries, opens, clicks, bounces.
