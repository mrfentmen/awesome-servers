# FEMA Disasters

US disaster declarations: search by state, type and date.

Keyless — no signup, no API key, no environment variables.

## Install

```bash
npx -y @mrfentmen/fema-disasters-mcp
```

## Tools

| Tool | What it does |
|---|---|
| `recent_disasters` | Most recent US disaster declarations |
| `disasters_by_state` | Disaster declarations for a US state |
| `disasters_by_type` | Declarations filtered by declaration type (DR, EM or FM) |
| `disasters_by_year` | Declarations for a fiscal year |
| `disaster_detail` | Declarations for one disaster number |

## Data source

FEMA OpenFEMA API
