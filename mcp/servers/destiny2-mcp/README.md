# destiny2-mcp

Bungie Destiny 2 API: search players, read profiles and characters, milestones and manifest.

## Setup

```bash
export BUNGIE_API_KEY=YOUR_KEY
```

## Tools

- `search_player` — Find a Destiny 2 player by display name across Bungie memberships.
- `get_profile` — Get a Destiny 2 profile: characters, inventory, progression. Components default to profile + characters.
- `get_character` — Get one Destiny 2 character: equipment, stats, progression, loadouts.
- `get_milestones` — Current Destiny 2 public milestones: Nightfall, raids, seasonal events with modifiers and rewards.
- `get_manifest` — Destiny 2 manifest index: version plus content paths for definitions (items, activities, lore).

Part of [awesome-mcps](https://github.com/mrfentmen/awesome-mcps).
