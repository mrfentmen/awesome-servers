# PeeringDB

Internet peering data: networks, exchange points and data-centre facilities.

Keyless — no signup, no API key, no environment variables.

## Install

```bash
npx -y @mrfentmen/peeringdb-mcp
```

## Tools

| Tool | What it does |
|---|---|
| `network_by_asn` | PeeringDB record for an ASN |
| `network_search` | Search PeeringDB networks by name |
| `exchange_search` | Search internet exchange points by name |
| `facility_search` | Search data-centre facilities by name |
| `network_contacts` | Peering contacts listed for an ASN |

## Data source

PeeringDB API
