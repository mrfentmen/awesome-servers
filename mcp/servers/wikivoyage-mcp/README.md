# wikivoyage-mcp

Wikivoyage travel guides: search destinations, overviews, section outlines, nearby places, outbound links, random picks.

## Tools

- `search_destinations`
- `destination_overview`
- `destination_sections`
- `nearby_destinations`
- `destination_links`
- `random_destination`

## Run

```bash
npm install && npm run build
npx wikivoyage-mcp
```

No key required. Keyless public API.
