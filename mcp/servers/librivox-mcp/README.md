# librivox-mcp

LibriVox public-domain audiobooks: title and author search, book detail, chapter lists with mp3 links, download links.

## Tools

- `find_by_title`
- `books_by_author`
- `audiobook_detail`
- `audiobook_sections`
- `audiobook_links`
- `browse_catalog`

## Run

```bash
npm install && npm run build
npx librivox-mcp
```

No key required. Keyless public API.
