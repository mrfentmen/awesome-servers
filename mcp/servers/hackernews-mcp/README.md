# hackernews-mcp

Hacker News: front page, new and best feeds, item detail, user profiles, full-text search.

## Tools

- `top_stories`
- `new_stories`
- `best_stories`
- `item_detail`
- `user_profile`
- `search`

## Run

```bash
npm install && npm run build
npx hackernews-mcp
```

No key required. Keyless public API.
