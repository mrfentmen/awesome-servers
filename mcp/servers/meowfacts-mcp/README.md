# meowfacts-mcp

Random cat facts from the free MeowFacts API. Great for warming up a conversation or a demo.

This file is self contained. It reads public data only and never writes to the machine. All output is bounded and honest about what could not be fetched.

## Tools


* `fact`  One random cat fact.
* `many`  Several cat facts.

## Usage

```bash
npm install
npm run build
node dist/index.js
```
