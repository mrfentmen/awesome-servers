# pypi-stats-mcp

PyPI download statistics: recent totals, daily series, Python and OS splits, package comparison.

## Tools

- `recent_downloads`
- `downloads_over_time`
- `python_versions`
- `system_breakdown`
- `compare_packages`
- `package_summary`

## Run

```bash
npm install && npm run build
npx pypi-stats-mcp
```

No key required. Keyless public API.
