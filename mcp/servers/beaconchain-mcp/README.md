# beaconchain-mcp

Ethereum beacon chain via beaconcha.in: chain state, validator rewards, latest epoch.

## Setup

```bash
export BEACONCHAIN_API_KEY=...
```

## Tools

- `get_chain_state` — Current Ethereum beacon chain state from beaconcha.in.
- `get_validator_rewards` — Rewards for beacon chain validators by index.
- `get_latest_epoch` — Latest beacon chain epoch summary (V1 API).

Part of [awesome-mcps](https://github.com/mrfentmen/awesome-mcps).
