# commafeed-mcp

Query the CommaFeed RSS reader REST API: feed entries, mark read/unread, entry tags, and feed subscribe. Works with any CommaFeed server via `COMMAFEED_BASE_URL` (default https://www.commafeed.com) with HTTP Basic `COMMAFEED_USERNAME`/`COMMAFEED_PASSWORD`.

## Tools

- `get_feed_entries` — Entries of a subscribed feed.
- `mark_entry` — Mark a feed entry read/unread.
- `list_entry_tags` — User's entry tags.
- `subscribe_feed` — Subscribe to a feed URL.
