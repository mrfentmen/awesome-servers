# AI Tomogotchi MCP

MCP server for an AI Tomogotchi virtual pet. Feed, play, and care for your AI pet.

## Tools

- `create_pet` - Create a new pet
- `feed_pet` - Feed your pet
- `play_with_pet` - Play with your pet
- `rest_pet` - Let your pet rest
- `heal_pet` - Heal your pet
- `check_pet` - Check pet status
- `age_pet` - Age your pet (decreases stats)
- `delete_pet` - Delete your pet

## Install

```bash
npx ai-tomogotchi-mcp
```

## Pet Stats

- `hunger` - 0-100 (higher is better)
- `happiness` - 0-100
- `energy` - 0-100
- `health` - 0-100
- `mood` - happy/sad/hungry/tired/sick/excited/bored
- `age` - increments with age_pet
