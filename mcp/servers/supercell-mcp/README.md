# supercell-mcp

Supercell API: Clash of Clans and Clash Royale players, clans, rankings. Key is IP-bound.

## Setup

```bash
export SUPERCELL_API_TOKEN=YOUR_KEY
```

Note: Supercell API keys are bound to your server IP addresses in the developer portal.

## Tools

- `get_coc_player` — Clash of Clans player profile: town hall, trophies, troops, achievements, clan.
- `get_coc_clan` — Clash of Clans clan: level, points, war record, member list.
- `search_coc_clans` — Search Clash of Clans clans by name.
- `get_royale_player` — Clash Royale player profile: trophies, wins, cards, current deck, clan.
- `get_royale_clan` — Clash Royale clan: score, donations, member list.
- `get_royale_top_clans` — Top Clash Royale clans for a location ranking.

Part of [awesome-mcps](https://github.com/mrfentmen/awesome-mcps).
