# pub.dev MCP

Dart and Flutter package details from pub.dev. Keyless — no signup, no API key, no environment variables.

## Install

```bash
npx -y @mrfentmen/pub-dev-mcp
```

Or add it to your MCP client:

```json
{
  "mcpServers": {
    "pub-dev-mcp": { "command": "npx", "args": ["-y", "@mrfentmen/pub-dev-mcp"] }
  }
}
```

## Tools

| Tool | What it does |
|---|---|
| `package` | Package details from pub.dev |

## Notes

pub.dev is the official Dart package registry. Metadata for every published package is public.
