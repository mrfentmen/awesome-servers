# National Grid Carbon

UK electricity carbon intensity, generation mix and forecast data.

Keyless — no signup, no API key, no environment variables.

## Install

```bash
npx -y @mrfentmen/grid-carbon-mcp
```

## Tools

| Tool | What it does |
|---|---|
| `current_intensity` | Current UK electricity carbon intensity |
| `generation_mix` | Current UK generation mix by fuel |
| `intensity_history` | Half-hourly carbon intensity between two timestamps |
| `intensity_for_date` | Carbon intensity for a whole day |
| `regional_intensity` | Carbon intensity by UK region |

## Data source

National Grid ESO Carbon Intensity API
