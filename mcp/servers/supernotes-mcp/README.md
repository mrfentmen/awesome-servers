# supernotes-mcp

Query the SuperNotes API: get cards, search/select cards, simple card creation, and auth check. API key (`SUPERNOTES_API_KEY`, header Api-Key) from Supernotes Settings > Manage Account > Manage API Keys.

## Tools

- `get_card` — SuperNotes card by UUID.
- `select_cards` — Search/select cards with optional query and limit.
- `simple_create_card` — Create a card with name/markup.
- `check_auth` — Validate the API key, returns user ID.
