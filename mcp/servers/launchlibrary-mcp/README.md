# Launch Library 2

Space launches, pads, agencies and events from the Launch Library 2 database.

Keyless — no signup, no API key, no environment variables.

## Install

```bash
npx -y @mrfentmen/launchlibrary-mcp
```

## Tools

| Tool | What it does |
|---|---|
| `upcoming_launches` | Next scheduled rocket launches |
| `launch_by_id` | Full detail for one launch by its id or slug |
| `search_launches` | Search past and future launches by name |
| `agencies` | Space agencies and launch providers |
| `pads` | Launch pads with coordinates |
| `events` | Recent space events such as dockings and landings |

## Data source

Launch Library 2 API
