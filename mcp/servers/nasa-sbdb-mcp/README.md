# JPL Small-Body Database

Asteroids and comets: orbital elements, close approaches and physical data.

Keyless — no signup, no API key, no environment variables.

## Install

```bash
npx -y @mrfentmen/nasa-sbdb-mcp
```

## Tools

| Tool | What it does |
|---|---|
| `object_lookup` | Identify an asteroid or comet and read its orbit class |
| `close_approaches` | Close approaches to Earth in a date range |
| `query_objects` | Query the small-body catalogue by kind |
| `count_objects` | Count objects of a kind in the catalogue |
| `orbit_classes` | Orbit class codes and what they mean |

## Data source

JPL SBDB API
