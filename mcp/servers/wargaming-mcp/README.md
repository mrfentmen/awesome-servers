# wargaming-mcp

Wargaming API: World of Tanks and World of Warships accounts, tank stats, clans.

## Setup

```bash
export WARGAMING_APP_ID=YOUR_KEY
```

## Tools

- `search_wot_accounts` — Find World of Tanks accounts by nickname.
- `get_wot_account` — World of Tanks account details: battles, wins, XP, clan, per-mode stats.
- `get_wot_tanks` — Per-vehicle World of Tanks stats for an account: battles, wins, damage, frags.
- `search_wot_clans` — Find World of Tanks clans by name or tag.
- `search_wows_accounts` — Find World of Warships accounts by nickname.
- `get_wows_account` — World of Warships account details: battles, wins, damage, clan, per-mode stats.

Part of [awesome-mcps](https://github.com/mrfentmen/awesome-mcps).
