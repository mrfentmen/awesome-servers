## Description
Your AdGuard Home DNS filter. Self-hosted (ADGUARD_URL). Not affiliated with the vendor.

## Setup Requirements
- Self-hosted URL or API credentials. See server README.

## Category
Developer Tools

## Features

- Protection status: DNS protection state: enabled, filters and upstreams.
- Statistics: Query and blocked-request counters, total and average.
- Query log: Recent DNS queries with client, domain and action.

## Getting Started

- "Protection on?"
- "Blocked queries?"
- Tool: get_status — DNS protection state: enabled, filters and upstreams.
- Tool: get_stats — Query and blocked-request counters, total and average.
- Tool: get_query_log — Recent DNS queries with client, domain and action.
