# DOAJ MCP

Search the Directory of Open Access Journals for free full-text articles. Keyless — no signup, no API key, no environment variables.

## Install

```bash
npx -y @mrfentmen/doaj-mcp
```

Or add it to your MCP client:

```json
{
  "mcpServers": {
    "doaj-mcp": { "command": "npx", "args": ["-y", "@mrfentmen/doaj-mcp"] }
  }
}
```

## Tools

| Tool | What it does |
|---|---|
| `search` | Search DOAJ open access articles |

## Notes

DOAJ lists vetted open access journals and their articles. Every result can be read for free.
