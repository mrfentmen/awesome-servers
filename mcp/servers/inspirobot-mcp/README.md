# inspirobot-mcp

Generate an inspirational AI art quote from InspiroBot. Returns the image URL of a machine made poster.

This file is self contained. It reads public data only and never writes to the machine. All output is bounded and honest about what could not be fetched.

## Tools


* `generate`  One generated inspirational quote image URL.

## Usage

```bash
npm install
npm run build
node dist/index.js
```
