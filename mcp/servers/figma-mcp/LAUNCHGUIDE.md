# Figma MCP

## Tagline
Files and projects. Token.

## Description
Files and projects. Token. Not affiliated with the vendor.

## Setup Requirements
- API credentials (free tier/sandbox). See server README.

## Category
Developer Tools

## Features
- team_projects: Projects in a team.
- file_comments: Comments on a file.
- file_versions: Version history.
- file_components: Published components.
- file_styles: Published styles.
- file_nodes: Nodes by IDs.
- file_images: PNG renders.

- My profile: The Figma user the access token belongs to.
- Get file: File metadata: name, pages and last modified date.
- Project files: Figma files inside one project id.

## Getting Started

- "Files in this project?"
- Tool: me — The Figma user the access token belongs to.
- Tool: get_file — File metadata: name, pages and last modified date.
- Tool: project_files — Figma files inside one project id.
