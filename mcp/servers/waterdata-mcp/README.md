# waterdata-mcp

USGS Water Services: gauge metadata, live and daily readings, state-wide gauge search, parameter lookup.

## Tools

- `site_info`
- `latest_reading`
- `readings_over_time`
- `daily_values`
- `find_sites_in_state`
- `parameter_lookup`

## Run

```bash
npm install && npm run build
npx waterdata-mcp
```

No key required. Keyless public API.
