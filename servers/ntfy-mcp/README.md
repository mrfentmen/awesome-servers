# ntfy-mcp

Use ntfy.sh (keyless; optional NTFY_BASE_URL + NTFY_TOKEN): publish notifications, poll a topic as JSON. Publishing is real.

## Tools

- `publish` — Send a REAL notification to a topic.
- `poll` — Cached messages as JSON.
