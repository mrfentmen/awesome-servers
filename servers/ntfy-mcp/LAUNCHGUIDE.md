## Tagline

## Description
Push via ntfy.sh. Keyless. Not affiliated with the vendor.

## Setup Requirements
- API credentials (free tier/sandbox). See server README.

## Category
Developer Tools

## Features
- health: ntfy server status.
- account: Tier and limits.
- poll_since: Messages after an ID.
- send_urgent: Max-priority REAL push.
- send_scheduled: Delayed REAL push.
- send_email: REAL email + push.
- send_call: REAL phone call.
- publish_tags: Push with emoji tags.

- Publish: Send a REAL notification to a topic.
- Poll messages: Messages cached on a topic, as JSON, since a given time.

## Getting Started

- "Push to my phone"
- Tool: publish — Send a REAL notification to a topic.
- Tool: poll — Messages cached on a topic, as JSON, since a given time.
