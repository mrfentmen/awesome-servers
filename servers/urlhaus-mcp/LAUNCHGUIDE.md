# URLhaus Threat Intel MCP

## Tagline
Malware URL lookup and feeds. Needs free key.

## Description
URLhaus malware URLs: recent, lookup, payloads. Needs free key.

## Setup Requirements
- API key as documented in README (all free tiers/self-serve).

## Category
Security

## Features

- Recent URLs: Recently added malicious URLs.
- Lookup URL: Check one URL against URLhaus.
- Lookup payload: Malware payload details for one SHA256 hash.
- Search tag: Malicious URLs carrying a malware tag, e.g. emotet.

## Getting Started

- "Check this URL"
- Tool: recent_urls — Recently added malicious URLs.
- Tool: lookup_url — Check one URL against URLhaus.
- Tool: lookup_payload — Malware payload details for one SHA256 hash.
- Tool: search_tag — Malicious URLs carrying a malware tag, e.g. emotet.
