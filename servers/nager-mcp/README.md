# nager-mcp

Fetch Nager.Date public holidays (keyless): countries, yearly holidays, upcoming holidays.

## Tools

- `list_countries` — Supported country codes.
- `get_holidays` — Holidays for a year and country.
- `next_holidays` — Next holidays for a country.
