# Public Holidays MCP

## Tagline
Worldwide public holidays and long weekends - no API key.

## Description
Plan around public holidays from your AI assistant: list countries, get a full holiday calendar for a country and year with local names, find the next upcoming holidays at home or worldwide, spot long weekends, and check whether today is a holiday. No key or account. An independent MCP server. Not affiliated with or endorsed by Nager.Date.

## Setup Requirements
No setup. Holiday data comes from the public Nager.Date API.

## Category
Productivity

## Features

- List countries: Every country the public holiday API covers, with its two-letter code.
- Country info: Official name, region and land borders for a country.
- Public holidays: All public holidays for a country and year, with local and English names.
- Upcoming holidays: The next public holidays for a country, starting from today.
- Holidays worldwide: The next public holidays around the world - useful for planning around other countries' closures.
- Long weekends: Long weekends in a country and year, and whether a bridge day off is needed to get them.
- Is today a holiday: Whether today is a public holiday in a country.

## Getting Started

- Ask your assistant about nager using this server once installed
- Tool: list_countries — Every country the public holiday API covers, with its two-letter code.
- Tool: country_info — Official name, region and land borders for a country.
- Tool: get_holidays — All public holidays for a country and year, with local and English names.
- Tool: next_holidays — The next public holidays for a country, starting from today.
- Tool: worldwide_holidays — The next public holidays around the world - useful for planning around other countries' closures.
- Tool: long_weekends — Long weekends in a country and year, and whether a bridge day off is needed to get them.
- Tool: is_today_holiday — Whether today is a public holiday in a country.
