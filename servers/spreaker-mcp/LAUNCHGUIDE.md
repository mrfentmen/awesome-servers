# Spreaker MCP

## Tagline
Spreaker shows, episodes and search. Public reads keyless.

## Description
Spreaker shows, episodes and search. Public reads keyless. Published from a private commercial monorepo. Not affiliated with or endorsed by Spreaker.

## Setup Requirements
- `SPREAKER_ACCESS_TOKEN` (required): set in your MCP client config before use.

## Category
Business Tools

## Features

- Get show: Retrieve a single Spreaker show by numeric ID.
- List show episodes: List episodes of a Spreaker show.
- Get episode: Retrieve a single Spreaker episode by numeric ID.
- Search shows: Search public Spreaker shows. No API key required.
- Create show: Create a new Spreaker show (requires SPREAKER_ACCESS_TOKEN).
