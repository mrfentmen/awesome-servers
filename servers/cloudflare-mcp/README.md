# cloudflare-mcp

Query Cloudflare v4 (API token; set CLOUDFLARE_API_TOKEN, Bearer): zones, accounts, DNS records.

## Tools

- `list_zones` — DNS zones.
- `list_accounts` — Accounts.
- `list_dns` — Records in a zone.
