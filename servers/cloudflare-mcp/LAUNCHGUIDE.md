# Cloudflare MCP

## Tagline
Zones and DNS. Token.

## Description
Zones and DNS. Token. Not affiliated with the vendor.

## Setup Requirements
- API credentials (free tier/sandbox). See server README.

## Category
Developer Tools

## Features
- zone_details: Single zone.
- dns_record: Single record.
- firewall_rules: Zone firewall.
- page_rules: Zone page rules.
- workers: Account scripts.
- analytics: 24h dashboard.
- tunnels: Cloudflare tunnels.

- List zones: Cloudflare zones (domains) in the account.
- List accounts: Cloudflare accounts the token can reach.
- List DNS: DNS records in one zone id, with type and TTL.

## Getting Started

- "DNS records?"
- Tool: list_zones — Cloudflare zones (domains) in the account.
- Tool: list_accounts — Cloudflare accounts the token can reach.
- Tool: list_dns — DNS records in one zone id, with type and TTL.
