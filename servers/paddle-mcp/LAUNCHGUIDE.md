# Paddle Billing MCP

## Tagline
Paddle products and prices. Needs a sandbox key (PADDLE_API_KEY).

## Description
Paddle products and prices. Needs a sandbox key (PADDLE_API_KEY). Not affiliated with the vendor.

## Setup Requirements
- Vendor API credentials (free tier/sandbox available). See server README.

## Category
Business Tools

## Features

- List products: Paddle products with price and status.
- Get product: One Paddle product by id, with price and status.
- List prices: Prices, optionally for one product.

## Getting Started

- "List my products"
- "Prices for this product?"
- Tool: list_products — Paddle products with price and status.
- Tool: get_product — One Paddle product by id, with price and status.
- Tool: list_prices — Prices, optionally for one product.
