# Deribit MCP

## Tagline
Deribit derivatives exchange: index prices, tickers, and supported indexes. No key required.

## Description
Deribit derivatives exchange: index prices, tickers, and supported indexes. No key required. Published from a private commercial monorepo. Not affiliated with or endorsed by Deribit.

## Setup Requirements
- No configuration required. Works out of the box with no API keys.

## Category
Other

## Features

- Index Price: Deribit index price for one index name, e.g. btc_usd.
- Ticker: Ticker for an instrument, e.g. BTC-PERPETUAL.
- Supported: Index names Deribit publishes prices for.
- Order book: Bids and asks with quantities for an instrument.
- Instruments: How many live instruments a currency and kind has, with a 10-name sample. Full list omitted for size.
- Last trades: Most recent trades for an instrument as time, direction, amount and price rows.
- Futures summary: Per-future last, mark and open interest rows for a currency.
