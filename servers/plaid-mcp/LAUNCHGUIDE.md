# Plaid Sandbox MCP

## Tagline
Bank data sandbox. ID + secret.

## Description
Bank data sandbox. ID + secret. Not affiliated with the vendor.

## Setup Requirements
- API credentials (free tier/sandbox). See server README.

## Category
Finance

## Features
- get_institution: By ID.
- sandbox_balance: Needs sandbox access token.
- sandbox_transactions: Needs sandbox access token.
- sandbox_holdings: Investment holdings.
- sandbox_liabilities: Loans/credit.
- sandbox_auth: Account/routing.
- sandbox_identity: Account holder.

- List institutions: Sandbox banks available for testing.
- List categories: Personal finance categories Plaid can return.
- Sandbox token: Create a test public token (sandbox only).

## Getting Started

- "Sandbox banks?"
- Tool: list_institutions — Sandbox banks available for testing.
- Tool: list_categories — Personal finance categories Plaid can return.
- Tool: sandbox_token — Create a test public token (sandbox only).
