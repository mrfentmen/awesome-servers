# raindrop-mcp

Query Raindrop.io (token; set RAINDROP_TOKEN, Bearer): user, collections, bookmarks.

## Tools

- `user` — Raindrop user.
- `collections` — Bookmark collections.
- `raindrops` — Links in a collection.
