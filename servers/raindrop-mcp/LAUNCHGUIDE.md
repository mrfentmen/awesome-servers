## Description
Bookmarks. Token. Not affiliated with the vendor.

## Setup Requirements
- API credentials (free tier). See server README.

## Category
Business Tools

## Features

- User: The Raindrop account the token belongs to.
- Collections: Bookmark collections with counts and ids.
- Bookmarks: Bookmarks in one collection, with tags and links.

## Getting Started

- "My bookmarks?"
- Tool: user — The Raindrop account the token belongs to.
- Tool: collections — Bookmark collections with counts and ids.
- Tool: raindrops — Bookmarks in one collection, with tags and links.
