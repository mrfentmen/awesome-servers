# Wise MCP

## Tagline
MCP server for Wise: profiles, balances, exchange rates. Needs a free Wise API token.

## Description
MCP server for Wise: profiles, balances, exchange rates. Needs a free Wise API token. Published from a private commercial monorepo. Not affiliated with or endorsed by Wise.

## Setup Requirements
- `WISE_API_TOKEN` (required): set in your MCP client config before use.

## Category
Finance

## Features
- List profiles: Your Wise profiles (personal, business) with ids.
- Get balances: Balances per currency for one Wise profile.
- Exchange rate: Current Wise mid-market rate between two currencies.

## Getting Started
- "Ask your assistant about wise using this server once installed"
- Tool: list_profiles — Your Wise profiles (personal, business) with ids.
- Tool: get_balances — Balances per currency for one Wise profile.
- Tool: exchange_rate — Current Wise mid-market rate between two currencies.
