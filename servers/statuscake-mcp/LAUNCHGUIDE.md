# Statuscake MCP

## Tagline
StatusCake API: uptime checks, history, alerts, monitoring locations. Needs API key.

## Description
StatusCake API: uptime checks, history, alerts, monitoring locations. Needs API key. Published from a private commercial monorepo. Not affiliated with or endorsed by Statuscake.

## Setup Requirements
- `STATUSCAKE_API_KEY` (required): set in your MCP client config before use.

## Category
Business Tools

## Features
- List uptime checks: All StatusCake uptime checks with status, URL and check rate.
- Get check detail: One StatusCake uptime check with full settings.
- Get check history: Uptime history for a check over a period.
- List monitoring locations: StatusCake monitoring locations for firewall allowlisting.

## Getting Started
- "Ask your assistant about statuscake using this server once installed"
- Tool: list_checks — All StatusCake uptime checks with status, URL and check rate.
- Tool: get_check — One StatusCake uptime check with full settings.
- Tool: get_history — Uptime history for a check over a period.
- Tool: list_locations — StatusCake monitoring locations for firewall allowlisting.
