# statuscake-mcp

StatusCake API: uptime checks, history, alerts, monitoring locations. Needs API key.

## Setup

```bash
export STATUSCAKE_API_KEY=...
```

## Tools

- `list_checks` — All StatusCake uptime checks with status, URL and check rate.
- `get_check` — One StatusCake uptime check with full settings.
- `get_history` — Uptime history for a check over a period.
- `list_locations` — StatusCake monitoring locations for firewall allowlisting.

Part of [awesome-mcps](https://github.com/mrfentmen/awesome-mcps).
