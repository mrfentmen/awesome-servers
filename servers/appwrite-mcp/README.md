# appwrite-mcp

Query your Appwrite instance (self-hosted or cloud; set APPWRITE_ENDPOINT + APPWRITE_PROJECT + APPWRITE_API_KEY): users, databases. Endpoints per official docs.

## Tools

- `list_users` — Project users.
- `list_databases` — Databases.
