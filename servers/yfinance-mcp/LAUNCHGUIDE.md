# Yfinance MCP

## Tagline
Yahoo Finance quotes and symbol search.

## Description
Yahoo Finance quotes and symbol search. Published from a private commercial monorepo. Not affiliated with or endorsed by Yfinance.

## Setup Requirements
- No configuration required. Works out of the box with no API keys.

## Category
Finance

## Features

- Quote: Get a stock quote and recent price data.
- Search: Search stock symbols by company name, e.g. apple.
- Search symbol: Search for a symbol by company name.
- Day gainers: Equities with the greatest gains today with price and percent change.
- Day losers: Equities with the greatest losses today with price and percent change.
- Most actives: Most actively traded equities with price and percent change.
- Trending tickers: Trending US ticker symbols. Use quote for prices.
