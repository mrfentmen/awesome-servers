# Yfinance MCP

## Tagline
Yahoo Finance quotes and symbol search.

## Description
Yahoo Finance quotes and symbol search. Published from a private commercial monorepo. Not affiliated with or endorsed by Yfinance.

## Setup Requirements
- No configuration required. Works out of the box with no API keys.

## Category
Finance

## Features
- Quote: Get a stock quote and recent price data.
- Search: Search stock symbols.
- Search symbol: Search for a symbol by company name.

## Getting Started
- "Ask your assistant about yfinance using this server once installed"
- Tool: quote — Get a stock quote and recent price data.
- Tool: search — Search stock symbols.
- Tool: search_symbol — Search for a symbol by company name.
