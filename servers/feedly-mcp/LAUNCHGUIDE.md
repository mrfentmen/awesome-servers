## Category

## Features

- Profile: The Feedly account the token belongs to.
- Subscriptions: Feeds the account follows, with titles.
- Stream contents: Recent entries in a stream, newest first.

## Getting Started

- "My feeds?"
- Tool: profile — The Feedly account the token belongs to.
- Tool: subscriptions — Feeds the account follows, with titles.
- Tool: stream_contents — Recent entries in a stream, newest first.
