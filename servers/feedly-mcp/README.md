# feedly-mcp

Query Feedly (token; set FEEDLY_TOKEN, Bearer): profile, subscriptions, stream contents.

## Tools

- `profile` — Feedly profile.
- `subscriptions` — Followed feeds.
- `stream_contents` — Recent entries.
