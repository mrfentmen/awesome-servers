# Nonprofits MCP

## Tagline
US nonprofit profiles and finances by EIN - no API key.

## Description
Research US nonprofits from your AI assistant: search by name, list organisations by state or NTEE category, pull a full profile for an EIN with address and latest revenue, trace revenue and expenses year by year, and compare up to five organisations side by side. No key or account. An independent MCP server. Not affiliated with or endorsed by the IRS.

## Setup Requirements
No setup. Data comes from public IRS filings via the ProPublica Nonprofit Explorer.

## Category
Other

## Features

- Search nonprofits: Search US nonprofits by name. Returns EIN, location and NTEE code for each match.
- Nonprofits by state: List nonprofits registered in a US state.
- Nonprofits by NTEE category: Find nonprofits by NTEE category, optionally within one state. Accepts the NTEE letter (A arts, B education, C environment, E health, P human services, S community) or a full code like 'B20'.
- Organisation details: Full profile for one EIN: address, ruling date, latest revenue and expenses, and a link to the newest Form 990.
- Financial history: Revenue, expenses and net result year by year for one EIN, with the change over the period.
- Compare nonprofits: Put up to 5 nonprofits side by side: location, category, revenue and expenses.
- Search by subsection: Nonprofits by IRS subsection: 501(c)(3), (c)(4), (c)(6) and the rest, optionally within one state.
- Filing history: Every Form 990 on record for one EIN: year, form type, revenue, expenses, assets and the PDF links.
