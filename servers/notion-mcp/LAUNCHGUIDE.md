## Features
- query_database: Rows of a database.
- block_children: Children blocks.
- search_databases: Databases by query.
- get_user: User details.
- append_block: Add a REAL paragraph.
- update_page_title: Set a REAL title.
- create_page: Create a REAL subpage.

- Search: Pages and databases the integration can reach, by title.
- List users: Users in the Notion workspace, with id, name and type.
- Get page: Properties of one page, by the page id.

## Getting Started

- "Find my page about X"
- Tool: search — Pages and databases the integration can reach, by title.
- Tool: list_users — Users in the Notion workspace, with id, name and type.
