# Cartesia Voices MCP

## Tagline
Cartesia text-to-speech voices and synthesis. Needs a free-tier key (CARTESIA_API_KEY).

## Description
Cartesia text-to-speech voices and synthesis. Needs a free-tier key (CARTESIA_API_KEY). Not affiliated with the vendor.

## Setup Requirements
- Vendor API credentials (free tier available). See server README.

## Category
Marketing

## Features

- List voices: Voices available on the account, with language.
- Get voice: One voice by id, with its embedding and settings.
- Synthesize speech: Render text to MP3 with a voice — this spends credits.

## Getting Started

- "List Cartesia voices"
- "Speak this text"
- Tool: list_voices — Voices available on the account, with language.
- Tool: get_voice — One voice by id, with its embedding and settings.
- Tool: synthesize_speech — Render text to MP3 with a voice — this spends credits.
