## Features

- List projects: Deepgram projects with IDs and names.
- Project balance: Credit balance for one Deepgram project.
- List API keys: API keys on the project, with scopes and created date.

## Getting Started

- "List my Deepgram projects"
- "What is my balance?"
- Tool: list_projects — Deepgram projects with IDs and names.
- Tool: get_balance — Credit balance for one Deepgram project.
- Tool: list_keys — API keys on the project, with scopes and created date.
