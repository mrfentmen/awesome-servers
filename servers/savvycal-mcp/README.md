# savvycal-mcp

Query the SavvyCal REST API: scheduling links, booked events, and current user. API token (`SAVVYCAL_API_TOKEN`) as Bearer required.

## Tools

- `list_links` — Scheduling links of the user.
- `get_link` — Scheduling link by ID.
- `get_current_user` — Authenticated SavvyCal user.
- `list_events` — Booked events.
