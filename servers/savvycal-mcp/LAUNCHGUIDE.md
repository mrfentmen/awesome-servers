## Description
SavvyCal scheduling links, events, user. Needs token. Published from a private commercial monorepo. Not affiliated with or endorsed by Savvycal.

## Setup Requirements
- `SAVVYCAL_API_TOKEN` (required): set in your MCP client config before use.

## Category
Business Tools

## Features
- List links: Scheduling links of the user.
- Get link: Scheduling link by ID.
- Current user: Authenticated SavvyCal user.
- List events: Booked events.

## Getting Started
- "Ask your assistant about savvycal using this server once installed"
- Tool: list_links — Scheduling links of the user.
- Tool: get_link — Scheduling link by ID.
- Tool: get_current_user — Authenticated SavvyCal user.
- Tool: list_events — Booked events.
