# Tiingo MCP

## Tagline
MCP server for Tiingo: stocks, forex, crypto. Needs a free API token.

## Description
MCP server for Tiingo: stocks, forex, crypto. Needs a free API token. Published from a private commercial monorepo. Not affiliated with or endorsed by Tiingo.

## Setup Requirements
- `TIINGO_API_TOKEN` (required): set in your MCP client config before use.

## Category
Finance

## Features
- Stock metadata: Stock name, exchange, data range.
- Recent prices: Recent daily OHLCV prices, newest first.
- Crypto metadata: Crypto name for a ticker.

## Getting Started
- "Ask your assistant about tiingo using this server once installed"
- Tool: stock_meta — Stock name, exchange, data range.
- Tool: stock_prices — Recent daily OHLCV prices, newest first.
- Tool: crypto_meta — Crypto name for a ticker.
