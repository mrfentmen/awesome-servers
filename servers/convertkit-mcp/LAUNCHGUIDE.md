## Description
MCP server for Kit (ConvertKit): subscribers, forms, broadcasts. Needs an API key. Published from a private commercial monorepo. Not affiliated with or endorsed by Convertkit.

## Setup Requirements
- `KIT_API_KEY` (required): set in your MCP client config before use.

## Category
Marketing & Social

## Features
- Find subscriber: Find a Kit subscriber by email: name, state, join date.
- List forms: Kit signup forms.
- List broadcasts: Kit email broadcasts (newsletters sent).

## Getting Started
- "Ask your assistant about convertkit using this server once installed"
- Tool: find_subscriber — Find a Kit subscriber by email: name, state, join date.
- Tool: list_forms — Kit signup forms.
- Tool: list_broadcasts — Kit email broadcasts (newsletters sent).
