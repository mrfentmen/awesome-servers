# linear-mcp

Query the Linear GraphQL API (key; set LINEAR_API_KEY, raw Authorization): viewer, teams, issue search.

## Tools

- `me` — Authenticated user.
- `list_teams` — Workspace teams.
- `search_issues` — Issues by text.
