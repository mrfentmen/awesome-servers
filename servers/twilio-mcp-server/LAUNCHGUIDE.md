# Twilio MCP

## Tagline

## Description
MCP server for Twilio communications. Send SMS, MMS, WhatsApp messages, make voice calls, and manage phone numbers. Published from a private commercial monorepo. Not affiliated with or endorsed by Twilio.

## Setup Requirements
- `TWILIO_ACCOUNT_SID` (required): set in your MCP client config before use.
- `TWILIO_AUTH_TOKEN` (required): set in your MCP client config before use.

## Category
Marketing & Social

## Features

- Send sms: Send an SMS text message to a phone number.
- Send mms: Send an MMS message with an image or media attachment.
- Send whatsapp: Send a WhatsApp message using Twilio.
- Get message status: Check the delivery status of a sent message.
- List messages: List recent messages with optional filters.
- Make call: Initiate a voice call. Requires a TwiML URL for call handling.
- List calls: Recent voice calls, with from, to, duration and status.
- List numbers: List your Twilio phone numbers.
- Search numbers: Search available phone numbers for purchase by area code.
