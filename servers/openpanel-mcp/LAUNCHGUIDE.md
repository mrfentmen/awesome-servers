## Tagline

## Description
OpenPanel analytics: metrics, live visitors, top pages, referrers. Needs client credentials. Published from a private commercial monorepo. Not affiliated with or endorsed by Openpanel.

## Setup Requirements
- `OPENPANEL_CLIENT_ID` (required): set in your MCP client config before use.
- `OPENPANEL_CLIENT_SECRET` (required): set in your MCP client config before use.

## Category
Data & Analytics

## Features

- Get metrics: OpenPanel visitors, sessions, bounce rate and engagement for a project.
- Get live visitors: Current active OpenPanel visitor count for a project.
- Get top pages: Top OpenPanel pages by sessions for a project.
- Get referrers: OpenPanel traffic sources for a project.

## Getting Started

- "Ask your assistant about openpanel using this server once installed"
- Tool: get_metrics — OpenPanel visitors, sessions, bounce rate and engagement for a project.
- Tool: get_live — Current active OpenPanel visitor count for a project.
- Tool: get_pages — Top OpenPanel pages by sessions for a project.
- Tool: get_referrer — OpenPanel traffic sources for a project.
