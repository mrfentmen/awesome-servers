# Loops MCP

## Tagline
MCP server for Loops: contacts, events. Needs a free API key.

## Description
MCP server for Loops: contacts, events. Needs a free API key. Published from a private commercial monorepo. Not affiliated with or endorsed by Loops.

## Setup Requirements
- `LOOPS_API_KEY` (required): set in your MCP client config before use.

## Category
Marketing & Social

## Features

- Find contact: Find a Loops contact by email.
- Create contact: Create a Loops contact with optional first/last name.
- Send event: Send a Loops event to trigger email flows.

## Getting Started

- "Ask your assistant about loops using this server once installed"
- Tool: find_contact — Find a Loops contact by email.
- Tool: create_contact — Create a Loops contact with optional first/last name.
- Tool: send_event — Send a Loops event to trigger email flows.
