# freshdesk-mcp

Query Freshdesk (set FRESHDESK_DOMAIN + FRESHDESK_API_KEY, key:X Basic): tickets, ticket details, contacts.

## Tools

- `list_tickets` — Recent tickets.
- `get_ticket` — Ticket details.
- `list_contacts` — Contacts.
