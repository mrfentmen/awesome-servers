# Freshdesk MCP

## Tagline
Tickets and contacts. Domain + key.

## Description
Tickets and contacts. Domain + key. Not affiliated with the vendor.

## Setup Requirements
- API credentials (free tier). See server README.

## Category
Business Tools

## Features
- contact_details: Single contact.
- agents: Support agents.
- companies: Customer companies.
- groups: Agent groups.
- conversations: Conversation on a ticket.
- satisfaction: CSAT ratings.
- canned: Reply templates.

- List tickets: Most recent support tickets, with status and priority.
- Get ticket: One ticket by id, with requester and full text.
- List contacts: Support contacts with email and company.

## Getting Started

- "Open tickets?"
- Tool: list_tickets — Most recent support tickets, with status and priority.
- Tool: get_ticket — One ticket by id, with requester and full text.
- Tool: list_contacts — Support contacts with email and company.
