# openrouter-mcp

Query OpenRouter (free key; set OPENROUTER_API_KEY, Bearer): model list, key info, credits.

## Tools

- `list_models` — Available LLM models.
- `key_info` — API key details and limits.
- `credits` — Credit balance.
