# Avianne MCP

## Tagline
Avianne Jewelers catalog: search, products, prices. Keyless.

## Description
Avianne Jewelers catalog: search, products, prices. Keyless. Published from a private commercial monorepo. Not affiliated with or endorsed by Avianne.

## Setup Requirements
- No configuration required. Works out of the box with no API keys.

## Category
Ecommerce

## Features

- Search products: Keyword search across the catalog.
- Newest arrivals: Newest catalog products, sorted by publish date.
- Get product: Full details: variants with parsed options, images, description, tags.
- Price overview: Ask-price distribution (min/p25/median/p75/max).
- Find deals: Available products priced below the median.
- Categories: Product-type counts in the catalog sample.
- List collections: Every store collection with its handle, for browse_collection, e.g. shop-all, accessories, uniform.
- Browse collection: Listings inside one collection handle from list_collections, optionally only items in stock in a size.
- Find by size: In-stock items in a size, with that size's price and the other sizes still in stock.
