# opsgenie-mcp

Query the Opsgenie API (free tier key; set OPSGENIE_API_KEY, sent as GenieKey): alerts, alert details, on-calls.

## Tools

- `list_alerts` — Alerts.
- `get_alert` — Alert details by ID.
- `list_oncalls` — Current on-call rotations.
