# vercel-mcp

Query the Vercel API (token; set VERCEL_TOKEN, Bearer): projects, project details, deployments.

## Tools

- `list_projects` — Vercel projects.
- `get_project` — Project details.
- `list_deployments` — Deployments, optionally per project.
