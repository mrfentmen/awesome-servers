# fbi-crime-mcp

Query the FBI Crime Data API (free key; set FBI_API_KEY from api.data.gov): arrests, offenses, victims by state.

## Tools

- `arrests` — Arrest estimates by state.
- `offenses` — Offense counts by state.
- `victims` — Victim demographics by state.
