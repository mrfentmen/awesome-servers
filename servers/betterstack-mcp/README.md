# betterstack-mcp

Query the Better Stack Uptime API (free tier key; set BETTERSTACK_API_KEY, Bearer): monitors, monitor details, incidents.

## Tools

- `list_monitors` — Uptime monitors.
- `get_monitor` — Monitor details by ID.
- `list_incidents` — Recent incidents.
