# Cocktail Recipes MCP

## Tagline
Cocktail search, recipes and random. Keyless.

## Description
CocktailDB recipes: search, lookup, random, ingredients. Keyless.

## Setup Requirements
- No configuration required. Works out of the box with no API keys.

## Category
Content & Media

## Features
- search_cocktails: Search by name
- get_cocktail: Full recipe by ID
- random_cocktail: A random recipe
- list_ingredients: All ingredients

## Getting Started
- "How do I make a margarita?"
- "Give me a random cocktail"
- Tool: search_cocktails — Search by name
- Tool: get_cocktail — Full recipe by ID
- Tool: random_cocktail — A random recipe
- Tool: list_ingredients — All ingredients
