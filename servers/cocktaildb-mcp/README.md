# cocktaildb-mcp

Query TheCocktailDB (keyless): cocktail search, full recipes with ingredients/measures, random cocktail, and ingredient list.

## Tools

- `search_cocktails` — Search by name.
- `get_cocktail` — Full recipe by drink ID.
- `random_cocktail` — A random recipe.
- `list_ingredients` — All known ingredients.
