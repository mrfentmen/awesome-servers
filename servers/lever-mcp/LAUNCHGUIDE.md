# Lever MCP

## Tagline
Job postings from Lever. No key required.

## Description
Job postings from Lever. No key required. Published from a private commercial monorepo. Not affiliated with or endorsed by Lever.

## Setup Requirements
- No configuration required. Works out of the box with no API keys.

## Category
Jobs

## Features

- Postings: List every open posting on a company Lever job board, with team, location and workplace type.
- Posting detail: Get one Lever posting by id, including the full plain-text description and apply link.
- Search postings: Search a company Lever board by title, team, department, location or commitment.
- Recent postings: A company's Lever postings sorted newest first, with the date each went up.
- Departments: A company's Lever postings grouped by department, ranked by how many are open.
- Teams: List the teams hiring on a company Lever board, ranked by number of postings.
- Locations: List where a company is hiring on Lever, with posting counts per location.
- Grouped postings: Lever's own server-side grouping: counts per team, department, location or commitment, with examples.
- Newest since: Postings added on or after a date - what changed on the board since you last looked.
