# fueleconomy-mcp

Query fueleconomy.gov (keyless XML API, parsed to JSON): makes, models, options, MPG.

## Tools

- `list_makes` — Makes for a model year.
- `list_models` — Models for year + make.
- `list_options` — Trims/engines for year + make + model.
- `get_mpg` — Driver-reported MPG for a vehicle ID.
