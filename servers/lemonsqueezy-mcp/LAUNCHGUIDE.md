# Lemon Squeezy MCP

## Tagline
Lemon Squeezy stores and products. Needs a test-mode key (LEMONSQUEEZY_API_KEY).

## Description
Lemon Squeezy stores and products. Needs a test-mode key (LEMONSQUEEZY_API_KEY). Not affiliated with the vendor.

## Setup Requirements
- Vendor API credentials (free tier/sandbox available). See server README.

## Category
Business Tools

## Features

- List stores: Lemon Squeezy stores on the account.
- List products: Products, optionally for one store.
- Get product: One product by id, with price and variants.

## Getting Started

- "List my stores"
- "Show products"
- Tool: list_stores — Lemon Squeezy stores on the account.
- Tool: list_products — Products, optionally for one store.
- Tool: get_product — One product by id, with price and variants.
