# Coinbase MCP

## Tagline
Crypto prices from Coinbase. No key required.

## Description
Crypto prices from Coinbase. No key required. Published from a private commercial monorepo. Not affiliated with or endorsed by Coinbase.

## Setup Requirements
- No configuration required. Works out of the box with no API keys.

## Category
Finance

## Features
- Spot: Spot price for a pair.
- Exchange: Exchange rates.

- Tool: exchange — Exchange rates.
