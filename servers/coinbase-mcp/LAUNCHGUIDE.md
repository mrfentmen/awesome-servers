# Coinbase MCP

## Tagline
Crypto prices from Coinbase. No key required.

## Description
Crypto prices from Coinbase. No key required. Published from a private commercial monorepo. Not affiliated with or endorsed by Coinbase.

## Setup Requirements
- No configuration required. Works out of the box with no API keys.

## Category
Other

## Features

- Spot: Latest spot price for one pair, e.g. BTC-USD.
- Exchange: Crypto-to-fiat exchange rates for one base currency.
- Buy price: Coinbase buy price for a pair, returns base, currency and amount.
- Sell price: Coinbase sell price for a pair, returns base, currency and amount.
- Currencies: How many currencies Coinbase supports with a fiat count and a 15-code sample. Full list omitted for size.
- Server time: Coinbase server time as ISO string and epoch, useful for timestamping quotes.
- Exchange stats: Coinbase Exchange 24h open, high, low, last and volume for a product, with the day's range.
- Candles: Coinbase Exchange OHLCV candles for a product at 1m to 1d granularity, with the period change.
- Exchange ticker: Live Coinbase Exchange ticker: price, bid/ask, spread, 24h volume and last trade id.
- Order book: Coinbase Exchange level-2 book: top bids and asks with sizes, order counts and the spread.
- Trading products: Coinbase Exchange products for a quote currency, e.g. every USD or USDT market, with online status.
