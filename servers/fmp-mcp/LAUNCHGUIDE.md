# Fmp MCP

## Tagline
MCP server for Financial Modeling Prep: quotes, profiles, financials. Free key.

## Description
MCP server for Financial Modeling Prep: quotes, profiles, financials. Free key. Published from a private commercial monorepo. Not affiliated with or endorsed by Fmp.

## Setup Requirements
- `FMP_API_KEY` (required): set in your MCP client config before use.

## Category
Finance

## Features

- Stock quote: Quote with day range and market cap.
- Company profile: Company: industry, CEO, website, description.
- Income statement: Recent annual revenue and net income in billions.

## Getting Started

- "Ask your assistant about fmp using this server once installed"
- Tool: stock_quote — Quote with day range and market cap.
- Tool: company_profile — Company: industry, CEO, website, description.
- Tool: income_statement — Recent annual revenue and net income in billions.
