# Cryptorank MCP

## Tagline
Crypto rankings from CryptoRank. No key required.

## Description
Crypto rankings from CryptoRank. No key required. Published from a private commercial monorepo. Not affiliated with or endorsed by Cryptorank.

## Setup Requirements
- No configuration required. Works out of the box with no API keys.

## Category
Finance

## Features

- Coins: Ranked coins with market cap and 24h change.
- Coin: One coin by its CryptoRank key, e.g. bitcoin.

## Getting Started

- "Ask your assistant about cryptorank using this server once installed"
- Tool: coins — Ranked coins with market cap and 24h change.
- Tool: coin — One coin by its CryptoRank key, e.g. bitcoin.
