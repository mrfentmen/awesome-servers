# stripe-mcp

Query the Stripe API (test-mode key; set STRIPE_SECRET_KEY, Basic): charges, customers, balance. Use test keys only.

## Tools

- `list_charges` — Recent charges.
- `list_customers` — Customers.
- `get_balance` — Account balance.
