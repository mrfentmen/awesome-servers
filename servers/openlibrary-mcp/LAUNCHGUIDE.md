# Open Library Books MCP

## Tagline
Book search, works and authors. Keyless.

## Description
Open Library books: search, works, authors. Keyless.

## Setup Requirements
- No configuration required. Works out of the box with no API keys.

## Category
Education & Research

## Features

- Search books: Search Open Library by title, author or free text. Returns authors, first publish year and cover links.
- Search by author: Find books by an author name across the whole Open Library catalog.
- Search by subject: Browse a subject or genre, e.g. 'science_fiction', 'cooking', 'biography'.
- Get work: Work details by ID (OL123W): description, subjects, first publish date and cover.
- Get edition: Edition details by ID (OL123M): publisher, page count, ISBNs and cover.
- Get author: Author details by ID (OL123A): birth/death dates, alternate names, bio and links.
- Author works: List the works credited to an author ID, with publication years.
