# openlibrary-mcp

Query the Open Library (openlibrary.org, keyless): full-text book search, work details, and author details with covers and publish years.

## Tools

- `search_books` — Full-text book search with covers and years.
- `get_work` — Work details by ID (OL123W or /works/OL123W).
- `get_author` — Author details by ID (OL23919A or /authors/OL23919A).
