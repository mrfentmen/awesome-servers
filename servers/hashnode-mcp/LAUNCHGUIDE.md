# Hashnode MCP

## Tagline
Blogs via GraphQL. Token.

## Description
Blogs via GraphQL. Token. Not affiliated with the vendor.

## Setup Requirements
- API credentials (free tier). See server README.

## Category
Developer Tools

## Features
- publication_info: About a blog.
- post_details: Single post.
- series_list: Blog series.
- tag_info: Tag details.
- user_stats: Follower count.
- user_publications: Blogs by a user.
- publication_members: Members and roles.

- My profile: The Hashnode user the token belongs to.
- Publication posts: Recent posts in a Hashnode publication.
- Get user: One Hashnode profile by username.

## Getting Started

- "Recent posts?"
- Tool: me — The Hashnode user the token belongs to.
- Tool: publication_posts — Recent posts in a Hashnode publication.
- Tool: get_user — One Hashnode profile by username.
