# hashnode-mcp

Query Hashnode GraphQL (token; set HASHNODE_TOKEN, raw Authorization; uses gql-beta endpoint): profile, publication posts, user.

## Tools

- `me` — Authenticated user.
- `publication_posts` — Recent posts.
- `get_user` — User profile.
