# Twitch MCP

## Tagline
Twitch games and live streams. Free token.

## Description
Twitch Helix API (free app token; TWITCH_CLIENT_ID + TWITCH_TOKEN). Not affiliated.

## Setup Requirements
- Free Twitch app credentials.

## Category
Entertainment

## Features

- Top games: Games with the biggest live viewer count right now.
- Top streams: Live streams, optionally for a game.
- Get user: Twitch profile for one login name, e.g. shroud.
- Search channels: Channels matching a query, with live status.

## Getting Started

- "Top games on Twitch?"
- "Who is streaming this game?"
- Tool: top_games — Games with the biggest live viewer count right now.
- Tool: top_streams — Live streams, optionally for a game.
- Tool: get_user — Twitch profile for one login name, e.g. shroud.
- Tool: search_channels — Channels matching a query, with live status.
