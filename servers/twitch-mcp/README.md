# twitch-mcp

Query the Twitch Helix API (free app token; set TWITCH_CLIENT_ID + TWITCH_CLIENT_SECRET (app access token is minted automatically)): top games, live streams, user profiles, channel search.

## Tools

- `top_games` — Games with the biggest live viewer count right now.
- `top_streams` — Live streams, optionally for a game.
- `search_channels` — Channels matching a query, with live status.
