# twitch-mcp

Query the Twitch Helix API (free app token; set TWITCH_CLIENT_ID + TWITCH_TOKEN): top games, live streams, channel search.

## Tools

- `top_games` — Most-watched games.
- `top_streams` — Live streams, optionally for a game.
- `search_channels` — Channels matching a query.
