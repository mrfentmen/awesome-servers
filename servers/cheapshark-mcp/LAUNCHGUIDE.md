# Cheapshark MCP

## Tagline
Find game deals and price history from CheapShark. No key required.

## Description
Find game deals and price history from CheapShark. No key required. Published from a private commercial monorepo. Not affiliated with or endorsed by Cheapshark.

## Setup Requirements
- No configuration required. Works out of the box with no API keys.

## Category
Business Tools

## Features
- Deals: Search current game deals.
- Store list: List stores tracked by CheapShark.

## Getting Started
- "Ask your assistant about cheapshark using this server once installed"
- Tool: deals — Search current game deals.
- Tool: store_list — List stores tracked by CheapShark.
