# Cheapshark MCP

## Tagline
Find game deals and price history from CheapShark. No key required.

## Description
Find game deals and price history from CheapShark. No key required. Published from a private commercial monorepo. Not affiliated with or endorsed by Cheapshark.

## Setup Requirements
- No configuration required. Works out of the box with no API keys.

## Category
Games

## Features

- Deals: Search current game deals under a price cap, optionally filtered by game title or store ID.
- Store list: List the game stores CheapShark tracks, with the store IDs used by the other tools.
- Search games: Find a game by title and get its cheapest current price plus the gameID for game_details.
- Game details: Compare one game's price across every store, plus its cheapest price ever.
- Top deals: The best current game deals ranked by CheapShark's deal rating, all stores or one store.
- Free games: Games currently free (or 100% off) on any tracked store.
- Steam lookup: Find a CheapShark game from its Steam AppID, with the current cheapest price and the gameID for game_details.
- Filter deals: Deals filtered by price range, minimum Metacritic score, minimum Steam rating, on-sale or AAA games, sorted cheapest first or by rating.
