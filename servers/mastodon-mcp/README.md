# mastodon-mcp

Read any Mastodon instance (keyless; set MASTODON_INSTANCE, default mastodon.social): trending tags, trending posts, instance info.

## Tools

- `trending_tags` — Trending hashtags.
- `trending_posts` — Trending statuses.
- `instance_info` — Instance details and stats.
