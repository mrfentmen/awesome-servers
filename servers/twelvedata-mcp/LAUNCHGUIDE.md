# Twelvedata MCP

## Tagline
Stock quotes from Twelve Data. Demo key supported.

## Description
Stock quotes from Twelve Data. Demo key supported. Published from a private commercial monorepo. Not affiliated with or endorsed by Twelvedata.

## Setup Requirements
- No configuration required. Works out of the box with no API keys.

## Category
Finance

## Features

- Quote: Latest quote for a symbol, e.g. AAPL: price and change.

## Getting Started

- "Ask your assistant about twelvedata using this server once installed"
- Tool: quote — Latest quote for a symbol, e.g. AAPL: price and change.
