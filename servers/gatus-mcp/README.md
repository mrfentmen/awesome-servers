# gatus-mcp

Query your Gatus instance (self-hosted; set GATUS_URL): endpoint list and status history. Endpoints per official docs.

## Tools

- `list_endpoints` — Monitored endpoints with status.
- `get_endpoint_statuses` — Status history for one endpoint.
