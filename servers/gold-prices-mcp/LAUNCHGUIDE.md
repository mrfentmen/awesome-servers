## Description
Gold and metal prices from gold-api.com (merged). Published from a private commercial monorepo. Not affiliated with or endorsed by Gold Prices.

## Setup Requirements
- No configuration required. Works out of the box with no API keys.

## Category

## Features
- Price: Current price for a metal.
- All: Prices for all tracked metals.

## Getting Started
- "Ask your assistant about gold prices using this server once installed"
- Tool: price — Current price for a metal.
- Tool: all — Prices for all tracked metals.
