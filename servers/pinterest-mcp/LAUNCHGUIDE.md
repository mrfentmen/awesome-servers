# Pinterest MCP

## Tagline
MCP server for Pinterest: account, boards, pins. Needs a free Pinterest access token.

## Description
MCP server for Pinterest: account, boards, pins. Needs a free Pinterest access token. Published from a private commercial monorepo. Not affiliated with or endorsed by Pinterest.

## Setup Requirements
- `PINTEREST_ACCESS_TOKEN` (required): set in your MCP client config before use.

## Category
Marketing & Social

## Features

- My account: Your Pinterest account: username, profile image, website.
- List boards: Your Pinterest boards: names, descriptions, pin counts.
- Get board: One Pinterest board with its pins.
- Get pin: One Pinterest pin: title, description, link, image.

## Getting Started

- "Ask your assistant about pinterest using this server once installed"
- Tool: my_account — Your Pinterest account: username, profile image, website.
- Tool: list_boards — Your Pinterest boards: names, descriptions, pin counts.
- Tool: get_board — One Pinterest board with its pins.
- Tool: get_pin — One Pinterest pin: title, description, link, image.
