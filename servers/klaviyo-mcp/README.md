# klaviyo-mcp

Query Klaviyo (private key; set KLAVIYO_API_KEY, Klaviyo-API-Key header + revision): profiles, lists, campaigns.

## Tools

- `list_profiles` — Customer profiles.
- `list_lists` — Marketing lists.
- `list_campaigns` — Campaigns.
