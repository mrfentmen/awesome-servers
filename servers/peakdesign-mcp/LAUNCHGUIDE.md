# Peak Design Gear MCP

## Tagline
Bags and camera gear search. Keyless.

## Description
Peak Design bags catalog: search, products, prices. Keyless. Not affiliated with the brand.

## Setup Requirements
- No configuration required. Works out of the box with no API keys.

## Category
Business Tools

## Features
- search_products: Keyword search
- list_newest: Newest arrivals
- get_product: Full details
- price_overview: Price stats
- find_deals: Below-median deals
- list_categories: Category counts

## Getting Started
- "Search this store"
- "Newest arrivals"
- "Anything under $100?"
