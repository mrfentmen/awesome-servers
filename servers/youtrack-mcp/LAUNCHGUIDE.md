# Youtrack MCP

## Tagline
YouTrack API: issue search, issue details, projects, comments. Needs permanent token.

## Description
YouTrack API: issue search, issue details, projects, comments. Needs permanent token. Published from a private commercial monorepo. Not affiliated with or endorsed by Youtrack.

## Setup Requirements
- `YOUTRACK_API_TOKEN` (required): set in your MCP client config before use.
- `YOUTRACK_BASE_URL` (required): set in your MCP client config before use.

## Category
Productivity

## Features
- Search issues: Search YouTrack issues with query language: 'project: WEB #Unresolved', 'for: me', sorted by updated.
- Get issue detail: One YouTrack issue with summary, description, state, assignee, timestamps.
- List projects: YouTrack projects with ids, names and short names.
- Get issue comments: Comments on a YouTrack issue with authors and timestamps.

## Getting Started
- "Ask your assistant about youtrack using this server once installed"
- Tool: search_issues — Search YouTrack issues with query language: 'project: WEB #Unresolved', 'for: me', sorted by updated.
- Tool: get_issue — One YouTrack issue with summary, description, state, assignee, timestamps.
- Tool: list_projects — YouTrack projects with ids, names and short names.
- Tool: get_issue_comments — Comments on a YouTrack issue with authors and timestamps.
