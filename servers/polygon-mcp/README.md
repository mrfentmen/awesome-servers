# polygon-mcp

Query Polygon.io (free key; set POLYGON_API_KEY, query param): tickers, ticker details, daily aggregates.

## Tools

- `list_tickers` — Reference tickers.
- `get_ticker` — Ticker details.
- `prev_close` — Last daily bar.
