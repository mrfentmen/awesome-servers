## Description
Paper trading. Key ID + secret. Not affiliated with the vendor.

## Setup Requirements
- API credentials (free tier/sandbox). See server README.

## Category
Finance

## Features
- order_details: Single order.
- position_details: Position in symbol.
- market_clock: Open/closed + times.
- calendar: Open days.
- list_assets: Tradable US equities.
- watchlists: Saved watchlists.
- portfolio_history: Equity curve.

- Account: Buying power, equity and cash for the trading account.
- Positions: Open positions with symbol, quantity and unrealized P/L.
- Orders: Recent orders with side, quantity, status and fill price.

## Getting Started

- "My paper positions?"
- Tool: account — Buying power, equity and cash for the trading account.
- Tool: positions — Open positions with symbol, quantity and unrealized P/L.
- Tool: orders — Recent orders with side, quantity, status and fill price.
