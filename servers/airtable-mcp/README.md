# airtable-mcp

Query the Airtable API (PAT; set AIRTABLE_TOKEN, Bearer): bases, tables, records.

## Tools

- `list_bases` — Accessible bases.
- `list_tables` — Tables in a base.
- `list_records` — Records in a table.
