## Tagline

## Description
Bases and records. PAT (AIRTABLE_TOKEN). Not affiliated with the vendor.

## Setup Requirements
- API credentials (free tier/sandbox). See server README.

## Category
Business Tools

## Features
- get_record: Single record.
- search_records: Formula filter.
- create_record: Create a REAL record.
- update_record: Update a REAL record.
- delete_record: Delete a REAL record.
- list_webhooks: Base webhooks.
- record_comments: Comments on a record.

- List bases: Airtable bases the token can access.
- List tables: Tables in one base, e.g. appXXXXXXXXXXXXXX.
- List records: Records in one table, with an optional max_records cap.

## Getting Started

- "Rows in my base?"
- Tool: list_bases — Airtable bases the token can access.
- Tool: list_tables — Tables in one base, e.g. appXXXXXXXXXXXXXX.
- Tool: list_records — Records in one table, with an optional max_records cap.
