# Apollo MCP

## Tagline
B2B search and enrich. Free key (APOLLO_API_KEY).

## Description
B2B search and enrich. Free key (APOLLO_API_KEY). Not affiliated with the vendor.

## Setup Requirements
- API credentials (free tier/sandbox). See server README.

## Category
Business Tools

## Features
- people_search: Prospects by keywords.
- company_search: Companies by name.
- org_enrich: Company by domain.
- bulk_match: Up to 10 emails.
- get_contact: Contact by ID.
- account_search: Accounts by name.
- people_search_v1: Prospects by job title.

- Account health: Check that the Apollo API key still works.
- Enrich person: Match one person by email, name or company.
- Search people: Prospect search by title, location and company size.

## Getting Started

- "Enrich this email"
- "Find prospects"
- Tool: health — Check that the Apollo API key still works.
- Tool: match_person — Match one person by email, name or company.
- Tool: search_people — Prospect search by title, location and company size.
