# Crisp MCP

## Tagline
Chat data per website. ID + key.

## Description
Chat data per website. ID + key. Not affiliated with the vendor.

## Setup Requirements
- API credentials (free tier). See server README.

## Category
Business Tools

## Features

- Visitors: Visitors on the site right now, with last page seen.
- People profile: Crisp profile for one email, with custom fields.
- Conversation: Messages in one conversation, by session id.

## Getting Started

- "Who is on my site?"
- Tool: list_visitors — Visitors on the site right now, with last page seen.
- Tool: get_profile — Crisp profile for one email, with custom fields.
- Tool: get_conversation — Messages in one conversation, by session id.
