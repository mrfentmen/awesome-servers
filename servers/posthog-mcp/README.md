# posthog-mcp

Query PostHog (personal key; set POSTHOG_PERSONAL_API_KEY, Bearer; optional POSTHOG_BASE_URL us/eu): profile, projects, insights.

## Tools

- `me` — PostHog user.
- `list_projects` — Analytics projects.
- `list_insights` — Saved insights.
