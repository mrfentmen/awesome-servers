# nylas-mcp

Query the Nylas v3 API (free tier key; set NYLAS_API_KEY, Bearer): grant info, calendars, recent messages.

## Tools

- `get_grant` — Authenticated grant details.
- `list_calendars` — Calendars on the grant.
- `list_messages` — Recent messages.
