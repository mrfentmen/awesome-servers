## Description
Ethereum token explorer: token info, address holdings, transaction history. No key required for low volume. Published from a private commercial monorepo. Not affiliated with or endorsed by Ethplorer.

## Setup Requirements
- No configuration required. Works out of the box with no API keys.

## Category
Other

## Features

- Token info: Get ERC-20 token details by address.
- Address info: Get token holdings for an address.
- Token history: Transfer history for a token address, newest first.
- Top tokens: Top ERC-20 tokens by activity with holder and transaction counts.
- Token holders: Largest holders of a token with balances and share percent.
- Address history: Token operations involving an address, newest first.
- Last block: Current Ethereum head block height, useful for timestamping the other lookups.
- ETH transfers: Latest plain ETH transfers for an address, with direction and USD value — token movements live in address_history.
- Transaction info: One Ethereum transaction by hash: status, sender, receiver, value, gas used and fee, plus token transfer and log counts.
