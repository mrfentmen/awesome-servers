ShootProof studio: brands, galleries, orders. Needs token. Published from a private commercial monorepo. Not affiliated with or endorsed by Shootproof.

## Setup Requirements
- `SHOOTPROOF_ACCESS_TOKEN` (required): set in your MCP client config before use.

## Category
Business Tools

## Features

- Service description: ShootProof API entry point with navigation links.
- Get me: Authenticated ShootProof user profile.
- List brands: Photography brands on the ShootProof account.
- List brand events: Galleries (events) of a brand.
- List brand orders: Orders of one ShootProof brand, newest first.
