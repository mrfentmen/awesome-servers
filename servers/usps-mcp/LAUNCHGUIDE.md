# USPS Shipping MCP

## Tagline
Rates, labels, tracking, address validation. Needs free key.

## Description
MCP server for USPS shipping, tracking, and address validation.

## Setup Requirements
- API key as documented in README where required (all free tiers/self-serve).

## Category
Business Tools

## Features
- get_rate: Rate estimates
- create_label: Shipping labels
- track_package: Package tracking
- validate_address: Address validation

## Getting Started
- "Track this package"
- "Rate to 90210"
- Tool: get_rate — Rate estimates
- Tool: create_label — Shipping labels
- Tool: track_package — Package tracking
- Tool: validate_address — Address validation
