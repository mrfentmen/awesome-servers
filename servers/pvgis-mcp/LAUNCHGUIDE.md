# Solar PV MCP

## Tagline
Solar yield, irradiation and system sizing - no API key.

## Description
Plan solar from your AI assistant: monthly and yearly PV output for any location, irradiation on a tilted plane, the typical weather year, hourly output series, a plain-language system verdict, side-by-side site comparison, and sizing for a target consumption. No key. An independent MCP server. Not affiliated with or endorsed by the EU JRC.

## Setup Requirements
No setup. Solar data comes from the public PVGIS API of the EU Joint Research Centre.

## Category
Other

## Features

- PV yield: Monthly and yearly solar output for a location. Give kWp and tilt, or leave tilt out to use the optimal angle.
- Solar irradiation: How much sun a site gets, month by month, on a tilted panel plane - with the year-to-year spread.
- Hourly series: Hour-by-hour solar data for one year, summarised by month: average irradiance, sun hours and temperature.
- Typical weather year: The typical meteorological year for a site: monthly temperature, humidity, wind speed and global irradiation.
- System summary: Plain-language verdict for a PV system: yearly output, yield per kWp, capacity factor, CO2 avoided and roof area.
- Compare sites: Compare up to 5 sites for the same system size and name the best one, e.g. '45,8; 52.5,13.4'.
- Size a system: Work out the system size needed to cover a target annual consumption at a location, with panel count and roof area.
