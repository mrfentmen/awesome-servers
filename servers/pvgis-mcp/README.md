# pvgis-mcp

Query EU PVGIS v5.3 (keyless): grid-connected PV yield, solar radiation, horizon data for any location.

## Tools

- `pv_yield` — Yearly/monthly PV output for a roof.
- `radiation` — Monthly irradiation averages.
