# hubspot-mcp

Query HubSpot (private-app token; set HUBSPOT_ACCESS_TOKEN, Bearer): contacts, companies, deals.

## Tools

- `list_contacts` — CRM contacts.
- `list_companies` — CRM companies.
- `list_deals` — CRM deals.
