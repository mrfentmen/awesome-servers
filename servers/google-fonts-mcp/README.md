# google-fonts-mcp

Query the Google Fonts Developer API (free Google key; set GOOGLE_FONTS_KEY, query param): font list, search, family details.

## Tools

- `list_fonts` — Most popular families.
- `search_fonts` — Families matching a name.
- `get_font` — Full metadata for a family.
