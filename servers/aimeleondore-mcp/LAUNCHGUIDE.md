# Aimeleondore MCP

## Tagline
Aimé Leon Dore catalog: search, products, prices. Keyless.

## Description
Aimé Leon Dore catalog: search, products, prices. Keyless. Published from a private commercial monorepo. Not affiliated with or endorsed by Aimeleondore.

## Setup Requirements
- No configuration required. Works out of the box with no API keys.

## Category
Business Tools

## Features

- Search products: Keyword search across the catalog.
- Newest arrivals: Newest catalog products, sorted by publish date.
- Get product: Full details: variants with parsed options, images, description, tags.
- Price overview: Ask-price distribution (min/p25/median/p75/max).
- Find deals: Available products priced below the median.
- Categories: Product-type counts in the catalog sample.

## Getting Started

- "Ask your assistant about aimeleondore using this server once installed"
