## Category

## Features

- DNS lookup: A/AAAA/MX/NS records for a domain. Keyless.
- Reverse DNS: PTR records for an IP address.
- Whois: WHOIS record for a domain or IP.
- GeoIP: Country/region/city for IP or domain.
- HTTP headers: Response headers for a URL, with status code.
- Reverse IP: Domains and hostnames hosted on one IP address.
