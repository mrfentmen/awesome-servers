# Jokes MCP

## Tagline
Safe-mode jokes by category, search and id - no API key.

## Description
Fetch jokes from your AI assistant: one joke or several, safe-mode categories like Programming and Pun, search by word, look up a joke by id, list every category and translation, check database stats, and grab a quick programmer joke. Safe mode is always on. No account or key. An independent MCP server. Not affiliated with or endorsed by JokeAPI.

## Setup Requirements
No setup. Jokes come from the public JokeAPI with safe mode always on.

## Category
Other

## Features

- Get a joke: One safe-mode joke, or several at once, optionally from a category like Programming or Pun.
- Search jokes: Find jokes that contain a word or phrase, e.g. 'chicken' or 'programmer'.
- Joke by id: Fetch one specific joke by its numeric id, so you can reuse the same joke.
- List categories: All safe-mode joke categories.
- Joke database info: How many jokes exist and how they break down by category.
- List languages: Languages the joke database is translated into.
- Programming joke: A quick programming joke - handy when you just want something to say to a developer.

## Getting Started

- Ask your assistant about jokeapi using this server once installed
- Tool: get_joke — One safe-mode joke, or several at once, optionally from a category like Programming or Pun.
- Tool: search_jokes — Find jokes that contain a word or phrase, e.g. 'chicken' or 'programmer'.
- Tool: joke_by_id — Fetch one specific joke by its numeric id, so you can reuse the same joke.
- Tool: list_categories — All safe-mode joke categories.
- Tool: joke_info — How many jokes exist and how they break down by category.
- Tool: list_languages — Languages the joke database is translated into.
- Tool: random_programming_joke — A quick programming joke - handy when you just want something to say to a developer.
