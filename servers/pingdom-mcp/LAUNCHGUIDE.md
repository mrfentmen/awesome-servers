# Pingdom MCP

## Tagline
Pingdom API: uptime checks, results, credits. Needs API token.

## Description
Pingdom API: uptime checks, results, credits. Needs API token. Published from a private commercial monorepo. Not affiliated with or endorsed by Pingdom.

## Setup Requirements
- `PINGDOM_API_TOKEN` (required): set in your MCP client config before use.

## Category
Business Tools

## Features
- List checks: All Pingdom uptime checks with current status and response time.
- Get check detail: One Pingdom check with full configuration.
- Get check results: Historical results for a check in a time window.
- Get credits: Remaining Pingdom API credits and rate-limit status.

## Getting Started
- "Ask your assistant about pingdom using this server once installed"
