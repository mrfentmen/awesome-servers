# pingdom-mcp

Pingdom API: uptime checks, results, credits. Needs API token.

## Setup

```bash
export PINGDOM_API_TOKEN=...
```

## Tools

- `list_checks` — All Pingdom uptime checks with current status and response time.
- `get_check` — One Pingdom check with full configuration.
- `get_results` — Historical results for a check in a time window.
- `get_credits` — Remaining Pingdom API credits and rate-limit status.

Part of [awesome-mcps](https://github.com/mrfentmen/awesome-mcps).
