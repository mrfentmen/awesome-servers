# Bigcommerce MCP

## Tagline
MCP server for BigCommerce: products, orders. Needs store API credentials.

## Description
MCP server for BigCommerce: products, orders. Needs store API credentials. Published from a private commercial monorepo. Not affiliated with or endorsed by Bigcommerce.

## Setup Requirements
- `BC_ACCESS_TOKEN` (required): set in your MCP client config before use.
- `BC_STORE_HASH` (required): set in your MCP client config before use.

## Category
Business Tools

## Features
- List products: BigCommerce catalog products with prices, SKUs, availability.
- Get product: One BigCommerce product by id.
- List orders: Recent BigCommerce orders: status, totals, customers.

## Getting Started
- "Ask your assistant about bigcommerce using this server once installed"
- Tool: list_products — BigCommerce catalog products with prices, SKUs, availability.
- Tool: get_product — One BigCommerce product by id.
- Tool: list_orders — Recent BigCommerce orders: status, totals, customers.
