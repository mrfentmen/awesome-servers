# calcom-mcp

Query Cal.com API v2 (key; set CAL_API_KEY, Bearer + version header): event types, bookings, schedules. v1 is decommissioned.

## Tools

- `list_event_types` — Scheduling links.
- `list_bookings` — Upcoming bookings.
- `list_schedules` — Availability schedules.
