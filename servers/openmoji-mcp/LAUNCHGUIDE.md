# OpenMoji MCP

## Tagline
Search 4500+ open-source emoji with SVG links - no API key.

## Description
Find the right emoji from your AI assistant: search the whole OpenMoji set by name, tag, group or subgroup, browse groups with counts, fetch one emoji with its hexcode and SVG link, and pull dataset statistics. Every emoji is open-licensed. No key or account. An independent MCP server. Not affiliated with or endorsed by OpenMoji.

## Setup Requirements
No setup. The OpenMoji dataset is fetched once and queried locally.

## Category
Other

## Features

- Search emoji: Search every OpenMoji emoji by annotation, tag, group or subgroup. Returns hexcode and SVG link.
- Get emoji details: Full record for one emoji: group, subgroup, tags and the official SVG link.
- List groups: The OpenMoji groups with how many emoji each contains.
- List subgroups: Subgroups inside one group, with emoji counts.
- List emojis in a group: Browse a group, optionally narrowed to one subgroup.
- Random emoji: Pick a random emoji, from the whole set or from one group.
- Dataset statistics: How big the OpenMoji set is right now: totals, groups, sequences and the largest group.
- SVG file links: The colour and black SVG files OpenMoji publishes for one emoji, each checked live so the URL, content type and file size are known before it is used.
- Skin tone variants: Every skin-tone variant OpenMoji publishes for an emoji, read from the dataset's own base links and labelled light through dark.
- Compare emoji: Compare two emoji on group, subgroup and tags with a tag-overlap score, to tell a near-duplicate apart from a genuinely different choice.
