# openmoji-mcp

Search the OpenMoji dataset (keyless, GitHub raw): emoji by keyword, details by hexcode, group list.

## Tools

- `search_emoji` — Emoji matching a keyword.
- `get_emoji` — Details by hexcode.
- `list_groups` — Emoji groups.
