# Postmark Email MCP

## Tagline
Postmark server, templates and outbound messages. Needs a server token (POSTMARK_SERVER_TOKEN).

## Description
Postmark server, templates and outbound messages. Needs a server token (POSTMARK_SERVER_TOKEN). Not affiliated with the vendor.

## Setup Requirements
- Vendor API credentials (free tier available). See server README.

## Category
Business Tools

## Features

- Server info: Postmark server details and delivery settings.
- List templates: Email templates on the server, with ids.
- Outbound messages: Recent outbound messages with recipient and status.

## Getting Started

- "Show my templates"
- "Recent outbound mail?"
- Tool: get_server — Postmark server details and delivery settings.
- Tool: list_templates — Email templates on the server, with ids.
- Tool: list_outbound — Recent outbound messages with recipient and status.
