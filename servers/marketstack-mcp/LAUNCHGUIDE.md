# Marketstack MCP

## Tagline
Marketstack API: end-of-day prices, historical EOD, ticker search, exchanges, dividends.

## Description
Marketstack API: end-of-day prices, historical EOD, ticker search, exchanges, dividends. Published from a private commercial monorepo. Not affiliated with or endorsed by Marketstack.

## Setup Requirements
- `MARKETSTACK_API_KEY` (required): set in your MCP client config before use.

## Category
Finance

## Features

- Get latest EOD prices: Latest end-of-day open/high/low/close/volume for stock symbols.
- Get EOD on date: End-of-day prices for symbols on one trading date.
- Search tickers: Search stock tickers by name or symbol: exchange, currency, MIC.
- List exchanges: Stock exchanges covered by Marketstack with MIC codes and countries.
- Get dividends: Dividend declarations for symbols: amount, pay date, record date.

## Getting Started

- Tool: get_dividends — Dividend declarations for symbols: amount, pay date, record date.
