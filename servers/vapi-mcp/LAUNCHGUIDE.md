# Vapi Voice Agents MCP

## Tagline
Vapi voice assistants and call history. Needs a free-tier key (VAPI_API_KEY).

## Description
Vapi voice assistants and call history. Needs a free-tier key (VAPI_API_KEY). Not affiliated with the vendor.

## Setup Requirements
- Vendor API credentials (free tier available). See server README.

## Category
Marketing

## Features

- List assistants: Voice assistants on the account, with id and model.
- Get assistant: One assistant by id, with its prompt and voice config.
- List calls: Call history with duration, cost and outcome.
- Get call: One call by id, with transcript and recording URL.

## Getting Started

- "List my voice assistants"
- "Show recent calls"
- Tool: list_assistants — Voice assistants on the account, with id and model.
- Tool: get_assistant — One assistant by id, with its prompt and voice config.
- Tool: list_calls — Call history with duration, cost and outcome.
- Tool: get_call — One call by id, with transcript and recording URL.
