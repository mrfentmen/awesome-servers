# Old School RuneScape MCP

## Tagline
Hiscores and Grand Exchange prices. Keyless.

## Description
MCP server for Old School RuneScape, player hiscores and Grand Exchange prices via the official wiki API.

## Setup Requirements
- API key as documented in README where required (all free tiers/self-serve).

## Category
Content & Media

## Features
- get_player_stats: Player hiscores
- get_item_price: GE buy/sell prices
- get_hot_items: Movers

## Getting Started
- "Abyssal whip price"
- Tool: get_player_stats — Player hiscores
- Tool: get_item_price — GE buy/sell prices
- Tool: get_hot_items — Movers
