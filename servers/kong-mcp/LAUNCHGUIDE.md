# Kong Gateway MCP

## Tagline
Your Kong gateway. Local Admin API.

## Description
Your Kong gateway. Local Admin API. Not affiliated with the vendor.

## Setup Requirements
- Self-hosted URL or API credentials. See server README.

## Category
Developer Tools

## Features

- Gateway status: Kong status counters: database and connections.
- List services: Services configured in Kong, with hosts.
- List routes: Routes configured in Kong, with paths.

## Getting Started

- "Gateway healthy?"
- "List services"
- Tool: get_status — Kong status counters: database and connections.
- Tool: list_services — Services configured in Kong, with hosts.
- Tool: list_routes — Routes configured in Kong, with paths.
