# Helius MCP

## Tagline
Helius Solana API: balances, transactions, NFTs, token metadata, parsed transactions.

## Description
Helius Solana API: balances, transactions, NFTs, token metadata, parsed transactions. Published from a private commercial monorepo. Not affiliated with or endorsed by Helius.

## Setup Requirements
- `HELIUS_API_KEY` (required): set in your MCP client config before use.

## Category
Finance

## Features

- Get wallet balances: Solana wallet balances via Helius: SOL plus every token holding with amounts and decimals.
- Get transactions: Recent Solana signatures for an address with slot and block time.
- Get wallet NFTs: NFTs held by a Solana wallet: collections, names, images.
- Get token metadata: Fungible token metadata for Solana mints: decimals, supply, name, symbol.
- Parse transactions: Human-readable Helius parse of Solana transactions: type, source, transfers, swaps.
