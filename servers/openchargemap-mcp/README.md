# openchargemap-mcp

Search Open Charge Map (free key; set OPENCHARGEMAP_API_KEY, query param): chargers near coordinates, details.

## Tools

- `nearby` — Chargers near coordinates.
- `get_poi` — Details by chargepoint ID.
