# directus-mcp

Query your Directus instance (self-hosted or cloud; set DIRECTUS_URL + DIRECTUS_TOKEN, Bearer): collections, users. Endpoints per official docs.

## Tools

- `list_collections` — Data collections.
- `list_users` — Directus users.
