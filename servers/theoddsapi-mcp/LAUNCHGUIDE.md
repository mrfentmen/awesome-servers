# Theoddsapi MCP

## Tagline
MCP server for The Odds API: sports, events, betting odds. Free key.

## Description
MCP server for The Odds API: sports, events, betting odds. Free key. Published from a private commercial monorepo. Not affiliated with or endorsed by Theoddsapi.

## Setup Requirements
- `THEODDS_API_KEY` (required): set in your MCP client config before use.

## Category
Data & Analytics

## Features
- List sports: Sports and leagues with API keys (soccer_epl, americanfootball_nfl...).
- Game odds: Upcoming games with bookmaker moneyline odds.

## Getting Started
- "Ask your assistant about theoddsapi using this server once installed"
- Tool: list_sports — Sports and leagues with API keys (soccer_epl, americanfootball_nfl...).
- Tool: game_odds — Upcoming games with bookmaker moneyline odds.
