# Mailjet MCP

## Tagline
MCP server for Mailjet: contacts, messages, campaigns. Needs free API keys.

## Description
MCP server for Mailjet: contacts, messages, campaigns. Needs free API keys. Published from a private commercial monorepo. Not affiliated with or endorsed by Mailjet.

## Setup Requirements
- `MJ_APIKEY_PRIVATE` (required): set in your MCP client config before use.
- `MJ_APIKEY_PUBLIC` (required): set in your MCP client config before use.

## Category
Marketing & Social

## Features
- List contacts: Mailjet contacts with names and unsubscribe flags.
- Recent messages: Recent sent emails: recipients, subjects, statuses.

## Getting Started
- "Ask your assistant about mailjet using this server once installed"
- Tool: list_contacts — Mailjet contacts with names and unsubscribe flags.
- Tool: recent_messages — Recent sent emails: recipients, subjects, statuses.
