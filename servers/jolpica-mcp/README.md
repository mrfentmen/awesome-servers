# jolpica-mcp

Query the Jolpica F1 API (Ergast-compatible, keyless): driver standings, constructor standings, schedule, results.

## Tools

- `drivers` — Driver championship standings for a season.
- `constructors` — Constructor standings for a season.
- `schedule` — Race calendar for a season, with dates.
- `last_race` — Results of the most recent race.
- `list_drivers` — Drivers entered in a season, with codes.
- `race_results` — Results for one round of a season.
