# Formula 1 MCP

## Tagline
F1 standings and schedules. Keyless.

## Description
F1 standings and schedules. Keyless. Not affiliated.

## Setup Requirements
- Free registration where noted, else none. See server README.

## Category
Entertainment

## Features

- Driver standings: Driver championship standings for a season.
- Constructor standings: Constructor standings for a season.
- Season schedule: Race calendar for a season, with dates.
- Last race: Results of the most recent race.
- List drivers: Drivers entered in a season, with codes.
- Race results: Results for one round of a season.

## Getting Started

- "F1 standings?"
- "This season races?"
- Tool: drivers — Driver championship standings for a season.
- Tool: constructors — Constructor standings for a season.
- Tool: schedule — Race calendar for a season, with dates.
- Tool: last_race — Results of the most recent race.
- Tool: list_drivers — Drivers entered in a season, with codes.
- Tool: race_results — Results for one round of a season.
