# slack-mcp

Query the Slack Web API (bot token; set SLACK_BOT_TOKEN, xoxb): channels, history, post messages. Posting is real.

## Tools

- `list_channels` — Workspace channels.
- `get_history` — Recent messages.
- `post_message` — Post a REAL message.
