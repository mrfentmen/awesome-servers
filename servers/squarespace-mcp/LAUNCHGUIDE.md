# Squarespace MCP

## Tagline
MCP server for Squarespace Commerce: products, orders, inventory. Needs an API key.

## Description
MCP server for Squarespace Commerce: products, orders, inventory. Needs an API key. Published from a private commercial monorepo. Not affiliated with or endorsed by Squarespace.

## Setup Requirements
- `SQUARESPACE_API_KEY` (required): set in your MCP client config before use.

## Category
Business Tools

## Features
- List products: Squarespace store products with prices and links.
- List orders: Recent Squarespace orders with totals and customer emails.

## Getting Started
- "Ask your assistant about squarespace using this server once installed"
- Tool: list_products — Squarespace store products with prices and links.
- Tool: list_orders — Recent Squarespace orders with totals and customer emails.
