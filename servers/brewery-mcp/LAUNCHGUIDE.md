# Brewery Finder MCP

## Tagline
US brewery search, details and random. Keyless.

## Description
Open Brewery DB: search breweries, details, random. Keyless.

## Setup Requirements
- No configuration required. Works out of the box with no API keys.

## Category
Other

## Features

- Search breweries: Search breweries on one specific field. Returns names, types, addresses, websites and ids.
- Search all fields: Free-text search across every brewery field — name, city, state, country, postal code and website — for when you do not know which field the text is in.
- Find breweries: List breweries matching structured filters — city, state, country, type and postal code — optionally sorted by name, city, state or type. Use it for questions like 'micro breweries in Vermont'.
- Get brewery: Full details for one brewery by its id, including address, coordinates and contact info.
- Random brewery: A random brewery from the directory, useful for discovery and examples.
- Brewery stats: Directory totals from Open Brewery DB broken down by country, brewery type and state/region. Good for market sizing and picking valid filter values.
