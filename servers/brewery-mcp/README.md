# brewery-mcp

Query Open Brewery DB (keyless): search US breweries by name/city/state/type, details, and random brewery.

## Tools

- `search_breweries` — Search by name, city, state or type.
- `get_brewery` — Brewery details by ID.
- `random_brewery` — A random US brewery.
