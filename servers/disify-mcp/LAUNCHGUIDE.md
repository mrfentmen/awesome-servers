# Disify MCP

## Tagline
Email validation from Disify. No key required.

## Description
Email validation from Disify. No key required. Published from a private commercial monorepo. Not affiliated with or endorsed by Disify.

## Setup Requirements
- No configuration required. Works out of the box with no API keys.

## Category
Developer Tools

## Features

- Check: Validate an email address: format, disposable domain, DNS records.
- Check domain: Validate an email domain: disposable, free provider, whitelist and DNS status.
- Check bulk: Validate up to 10 email addresses in one call and count how many are disposable.
- MX records: List the MX mail hosts for a domain, useful for checking whether a mailbox can receive mail.
- DNS lookup: Resolve live DNS records for a domain — A, AAAA, MX, NS, TXT, CNAME, SOA, CAA, PTR or SRV — via public DNS-over-HTTPS.
- Domain summary: One report on a domain: disposable verdict plus live A, NS and MX records, so you can tell whether signups from it are trustworthy.
