# hibp-mcp

Query HaveIBeenPwned (free key; set HIBP_API_KEY, sent as hibp-api-key with a User-Agent): breach check for an account, full breach catalog, pastes for an email.

## Tools

- `check_account` — Breaches for an account/email.
- `list_breaches` — All known breaches.
- `check_pastes` — Pastes containing an email.
