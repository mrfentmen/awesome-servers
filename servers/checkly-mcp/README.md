# checkly-mcp

Query the Checkly API (free tier key; set CHECKLY_API_KEY, Bearer): checks, check details, check results.

## Tools

- `list_checks` — API and browser checks.
- `get_check` — Check config by ID.
- `list_results` — Recent results for a check.
