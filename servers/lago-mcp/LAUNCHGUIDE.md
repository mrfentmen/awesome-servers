# Lago Billing MCP

## Tagline
Lago plans, customers and invoices. Needs a key (LAGO_API_KEY).

## Description
Lago plans, customers and invoices. Needs a key (LAGO_API_KEY). Not affiliated with the vendor.

## Setup Requirements
- Vendor API credentials (free tier/sandbox available). See server README.

## Category
Business Tools

## Features

- List plans: Billing plans with interval and amount.
- List customers: Billing customers with id and currency.
- List invoices: Invoices with status, amount and billing period.

## Getting Started

- "List billing plans"
- "Recent invoices?"
- Tool: list_plans — Billing plans with interval and amount.
- Tool: list_customers — Billing customers with id and currency.
- Tool: list_invoices — Invoices with status, amount and billing period.
