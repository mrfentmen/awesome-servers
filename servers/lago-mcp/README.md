# lago-mcp

Query the Lago API (free self-host or cloud key; set LAGO_API_KEY, Bearer; optional LAGO_BASE_URL): plans, customers, invoices.

## Tools

- `list_plans` — Billing plans.
- `list_customers` — Customers.
- `list_invoices` — Invoices.
