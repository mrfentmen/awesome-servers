# Blockchain Info MCP

## Tagline
Bitcoin data from blockchain.info: price ticker, latest block, and address balances. No key required

## Description
Bitcoin data from blockchain.info: price ticker, latest block, and address balances. No key required. Published from a private commercial monorepo. Not affiliated with or endorsed by Blockchain Info.

## Setup Requirements
- No configuration required. Works out of the box with no API keys.

## Category
Finance

## Features

- Ticker: Bitcoin price in USD, EUR, GBP, JPY and BTC, with buy/sell spreads.
- Latest block: The latest Bitcoin block: height, hash, mining time and transaction count.
- Network stats: Bitcoin network health: hash rate, difficulty, block pace, 24h transaction count, miner revenue and total coins mined.
- Address: Bitcoin address summary: transaction count, total received/sent, balance and recent transactions.
- Address balances: Check the balance of up to 20 Bitcoin addresses at once, comma or space separated.
- Transaction: Look up a Bitcoin transaction by hash: size, fee, inputs, outputs and the largest payments.
