# Folk CRM MCP

## Tagline
Folk contacts and groups. Needs a key (FOLK_API_KEY).

## Description
Folk contacts and groups. Needs a key (FOLK_API_KEY). Not affiliated with the vendor.

## Setup Requirements
- Vendor API credentials (free tier/sandbox available). See server README.

## Category
Business Tools

## Features

- List people: Contacts in the Folk workspace, newest first.
- Get person: One contact by id, with emails and company.
- List groups: Contact groups with id and name.

## Getting Started

- "List my contacts"
- "Show groups"
- Tool: list_people — Contacts in the Folk workspace, newest first.
- Tool: get_person — One contact by id, with emails and company.
- Tool: list_groups — Contact groups with id and name.
