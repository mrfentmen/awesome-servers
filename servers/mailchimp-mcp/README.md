# mailchimp-mcp

Query Mailchimp (key; set MAILCHIMP_API_KEY, datacenter derived from key suffix): ping, lists, members, campaigns.

## Tools

- `ping` — API health.
- `list_lists` — Mailchimp audiences.
- `list_members` — Members of an audience.
- `list_campaigns` — Campaigns.
