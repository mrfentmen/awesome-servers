# Appveyor MCP

## Tagline
AppVeyor CI: projects, last builds, history. Needs API token.

## Description
AppVeyor CI: projects, last builds, history. Needs API token. Published from a private commercial monorepo. Not affiliated with or endorsed by Appveyor.

## Setup Requirements
- `APPVEYOR_API_TOKEN` (required): set in your MCP client config before use.

## Category
Business Tools

## Features
- List projects: All AppVeyor projects with last build status.
- Get project build: Latest AppVeyor build for a project with jobs and status.
- Get build history: Recent AppVeyor builds for a project branch.

## Getting Started
- "Ask your assistant about appveyor using this server once installed"
- Tool: list_projects — All AppVeyor projects with last build status.
- Tool: get_project — Latest AppVeyor build for a project with jobs and status.
- Tool: get_history — Recent AppVeyor builds for a project branch.
