# Quip MCP

## Tagline
Quip Automation API: thread search, thread content, folders. Needs token.

## Description
Quip Automation API: thread search, thread content, folders. Needs token. Published from a private commercial monorepo. Not affiliated with or endorsed by Quip.

## Setup Requirements
- `QUIP_API_TOKEN` (required): set in your MCP client config before use.

## Category
Business Tools

## Features

- Search threads: Search Quip docs, spreadsheets and chats by text.
- Get thread: Quip thread with document HTML content.
- List folders: Quip folders including shared folders.
- Get current user: Authenticated Quip user profile.

## Getting Started

- "Ask your assistant about quip using this server once installed"
