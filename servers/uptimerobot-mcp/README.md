# uptimerobot-mcp

Query the UptimeRobot v2 API (free key; set UPTIMEROBOT_API_KEY, sent as api_key form param): monitors, monitor details, account info.

## Tools

- `list_monitors` — Monitors with status.
- `get_monitor` — Monitor details, logs, response times.
- `get_account` — Account details and limits.
