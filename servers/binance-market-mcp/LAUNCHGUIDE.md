# Binance Market MCP

## Tagline
Live crypto prices, tickers, and candlestick charts from Binance public data. No key required.

## Description
Live crypto prices, tickers, and candlestick charts from Binance public data. No key required. Published from a private commercial monorepo. Not affiliated with or endorsed by Binance Market.

## Setup Requirements
- No configuration required. Works out of the box with no API keys.

## Category
Finance

## Features
- Ticker: Get the 24 hour ticker for a symbol.
- Klines: Get candlestick data for a symbol.
- Price: Get the current price for a symbol.

## Getting Started
- "Ask your assistant about binance market using this server once installed"
- Tool: ticker — Get the 24 hour ticker for a symbol.
- Tool: klines — Get candlestick data for a symbol.
- Tool: price — Get the current price for a symbol.
