# mobygames-mcp

Query the MobyGames API (free key; set MOBYGAMES_API_KEY): game search across 300k+ titles incl. retro, and details.

## Tools

- `search_games` — Title search incl. retro (needs MOBYGAMES_API_KEY).
- `get_game` — Game details by ID.
