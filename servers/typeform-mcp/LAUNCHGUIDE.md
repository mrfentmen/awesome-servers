# Typeform MCP

## Tagline
Forms and responses. Token.

## Description
Forms and responses. Token. Not affiliated with the vendor.

## Setup Requirements
- API credentials (free tier). See server README.

## Category
Business Tools

## Features
- find_response: Response by token.
- account_images: Image library.
- account_image: Single image.
- themes: All themes.
- theme_details: Single theme.
- workspaces: All workspaces.
- create_form: Create a REAL empty form.

- List forms: All Typeform forms, with id and title.
- Get form: One form's structure: fields, logic and settings.
- Responses: Recent responses to a form, newest first.

## Getting Started

- "Recent responses?"
- Tool: list_forms — All Typeform forms, with id and title.
- Tool: get_form — One form's structure: fields, logic and settings.
- Tool: list_responses — Recent responses to a form, newest first.
