# customerio-mcp

Query Customer.io (set CUSTOMERIO_SITE_ID + CUSTOMERIO_API_KEY, Basic): customers, customer details, segments.

## Tools

- `list_customers` — Tracked customers.
- `get_customer` — Customer profile.
- `list_segments` — Segments.
