# Customer.io MCP

## Tagline
Customers and segments. Site ID + key.

## Description
Customers and segments. Site ID + key. Not affiliated with the vendor.

## Setup Requirements
- API credentials (free tier). See server README.

## Category
Business Tools

## Features
- segment_details: Single segment.
- campaigns: All campaigns.
- campaign_details: Single campaign.
- newsletters: All newsletters.
- activities: Workspace activity.
- customer_activities: Activity for a customer.
- customer_messages: Messages for a customer.

- List customers: Tracked customers with email and attributes.
- Get customer: One customer profile by id, with its attributes.
- List segments: Segments with id, name and member counts.

## Getting Started

- "Find this customer"
- Tool: list_customers — Tracked customers with email and attributes.
- Tool: get_customer — One customer profile by id, with its attributes.
- Tool: list_segments — Segments with id, name and member counts.
