## Description
MCP server for beehiiv: publications, posts, subscribers. Needs an API key. Published from a private commercial monorepo. Not affiliated with or endorsed by Beehiiv.

## Setup Requirements
- `BEEHIIV_API_KEY` (required): set in your MCP client config before use.

## Category
Marketing & Social

## Features

- List posts: beehiiv publication posts with statuses and links.
- Find subscriber: Find a beehiiv subscriber by email: status, tier, join date.

## Getting Started

- "Ask your assistant about beehiiv using this server once installed"
