# Coingecko MCP

## Tagline
CoinGecko prices and trending coins.

## Description
CoinGecko prices and trending coins. Published from a private commercial monorepo. Not affiliated with or endorsed by Coingecko.

## Setup Requirements
- No configuration required. Works out of the box with no API keys.

## Features
- Price: Price for one coin.
- Trending: Trending coins.

- Tool: trending — Trending coins.
