# Coingecko MCP

## Tagline
CoinGecko prices and trending coins.

## Description
CoinGecko prices and trending coins. Published from a private commercial monorepo. Not affiliated with or endorsed by Coingecko.

## Setup Requirements
- No configuration required. Works out of the box with no API keys.

## Category
Finance

## Features

- Price: Current price for one coin id, e.g. bitcoin, in a chosen currency.
- Trending: Coins trending in CoinGecko search over the last 24 hours.
- Top markets: Top coins by market cap with rank and price.
- Coin detail: One coin with rank, 24h change, algorithm and categories.
- Price chart: Sampled daily closes for a coin over N days with the period percent change.
- Global stats: Total coins and markets plus top-5 dominance shares.
