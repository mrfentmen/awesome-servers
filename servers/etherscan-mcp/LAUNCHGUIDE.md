## Description
EVM balances and transactions. Free key (ETHERSCAN_API_KEY). Not affiliated with the vendor.

## Setup Requirements
- API credentials (free tier/sandbox). See server README.

## Category
Finance

## Features
- tx_status: Receipt status by hash.
- contract_abi: Verified ABI.
- contract_source: Verified source info.
- token_balance: ERC-20 balance.
- gas_oracle: Current gas tiers.
- eth_price: ETH/USD price.
- block_number: Latest block.

- ETH balance: Native balance for an address.
- Transactions: Recent normal transactions for an address.
- Token transfers: Recent ERC-20 transfers to or from an address.

## Getting Started

- "Balance of 0x...?"
- Tool: get_balance — Native balance for an address.
- Tool: get_transactions — Recent normal transactions for an address.
- Tool: get_token_transfers — Recent ERC-20 transfers to or from an address.
