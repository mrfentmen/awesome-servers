# Turbosquid MCP

## Tagline
TurboSquid 3D: file formats, products, seller drafts.

## Description
TurboSquid 3D: file formats, products, seller drafts. Published from a private commercial monorepo. Not affiliated with or endorsed by Turbosquid.

## Setup Requirements
- `TURBOSQUID_API_TOKEN` (required): set in your MCP client config before use.

## Category
Business Tools

## Features

- List file formats: 3D file formats with extensions and renderers (requires TURBOSQUID_API_TOKEN).
- Get product: 3D model product metadata by numeric product ID.
- List drafts: New product drafts of the authenticated member (requires TURBOSQUID_API_TOKEN).
- Get draft: Draft metadata by draft ID (requires TURBOSQUID_API_TOKEN).
