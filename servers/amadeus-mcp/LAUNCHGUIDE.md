## Description
MCP server for Amadeus travel: flights, hotels, airports. Free test key. Published from a private commercial monorepo. Not affiliated with or endorsed by Amadeus.

## Setup Requirements
- `AMADEUS_API_KEY` (required): set in your MCP client config before use.
- `AMADEUS_API_SECRET` (required): set in your MCP client config before use.

## Category

## Features
- Search airports: Airport codes by city name.
- Search flights: Flight offers with prices and legs (test environment data).
