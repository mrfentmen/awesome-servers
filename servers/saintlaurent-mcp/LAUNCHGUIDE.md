# Saintlaurent MCP

## Tagline
Saint Laurent resale listings from Fashionphile and Rebag. Keyless.

## Description
Saint Laurent resale listings from Fashionphile and Rebag. Keyless. Published from a private commercial monorepo. Not affiliated with or endorsed by Saintlaurent.

## Setup Requirements
- No configuration required. Works out of the box with no API keys.

## Category
Ecommerce

## Features

- Search listings: Keyword search across Fashionphile and Rebag. Condition filter is Rebag-data only.
- Newest listings: Newest catalog listings, sorted by publish date.
- Get listing: Full details: variants, images, parsed condition/color/material, description.
- Price overview: Ask-price stats overall + by condition.
- Compare prices: Group same-model listings across sources with min/max/spread.
- Find deals: Available listings priced below the brand median.
- Brand overview: Catalog sample counts by source, type and condition.
- List collections: Curated store collections with handles for browse_collection, e.g. sale or category collections.
- Browse collection: Listings inside one collection handle from list_collections, e.g. a sale or category collection.
- Find by attribute: Listings filtered by color, exterior material or condition, plus the common values in the sample.
