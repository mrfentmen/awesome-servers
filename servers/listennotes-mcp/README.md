# listennotes-mcp

Query Listen Notes (free key; set LISTENNOTES_API_KEY, X-ListenAPI-Key): podcast search, best lists, episode details.

## Tools

- `search` — Episodes matching a query.
- `best_podcasts` — Curated best lists.
- `get_episode` — Episode details.
