# Jobicy MCP

## Tagline
Remote jobs from Jobicy. No key required.

## Description
Remote jobs from Jobicy. No key required. Published from a private commercial monorepo. Not affiliated with or endorsed by Jobicy.

## Setup Requirements
- No configuration required. Works out of the box with no API keys.

## Category
Business Tools

## Features

- Jobs: List remote jobs, filtered by region (geo), industry or skill tag.
- Job details: Get full descriptions for jobs matching a title, company or skill, searched across the 50 most recent postings.
- Industries: List the industries hiring the most remote workers right now, with open job counts.
- Top salaries: List the highest-paying remote jobs that publish a salary, annualized for comparison.
- Companies hiring: Rank the companies with the most open remote jobs, including how many disclosed pay and the top published salary.
- Levels and pay: Break remote hiring down by experience level and employment type, with the highest published salary in each level.
