# Blubrry MCP

## Tagline
Blubrry podcast hosting: shows, media, download stats. Needs token.

## Description
Blubrry podcast hosting: shows, media, download stats. Needs token. Published from a private commercial monorepo. Not affiliated with or endorsed by Blubrry.

## Setup Requirements
- `BLUBRRY_ACCESS_TOKEN` (required): set in your MCP client config before use.

## Category
Business Tools

## Features

- List shows: List podcast shows on the Blubrry account.
- List show media: Unpublished and recently published media files for a show.
- Show stats summary: Overall download summary for a show.
- Show episode stats: Episode-level download counts for a show.
- Show stats totals: Lifetime download totals for a show.

## Getting Started

- "Ask your assistant about blubrry using this server once installed"
- Tool: list_shows — List podcast shows on the Blubrry account.
- Tool: list_show_media — Unpublished and recently published media files for a show.
- Tool: get_show_stats_summary — Overall download summary for a show.
- Tool: get_show_episode_stats — Episode-level download counts for a show.
- Tool: get_show_stats_totals — Lifetime download totals for a show.
