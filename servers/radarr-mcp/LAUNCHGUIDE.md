# Radarr MCP

## Tagline
Your Radarr movie library. Self-hosted (RADARR_URL + RADARR_API_KEY).

## Description
Your Radarr movie library. Self-hosted (RADARR_URL + RADARR_API_KEY). Not affiliated with the vendor.

## Setup Requirements
- Self-hosted URL or API credentials. See server README.

## Category
Entertainment

## Features

- List movies: Movies in the Radarr library, with status.
- Download queue: Active downloads and imports in the queue.
- Health checks: Radarr health warnings and errors.

## Getting Started

- "List my movies"
- "What is downloading?"
- Tool: list_movies — Movies in the Radarr library, with status.
- Tool: get_queue — Active downloads and imports in the queue.
- Tool: get_health — Radarr health warnings and errors.
