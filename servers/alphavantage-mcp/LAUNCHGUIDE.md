# Alphavantage MCP

## Tagline
MCP server for Alpha Vantage: stock quotes, forex, crypto. Needs a free API key.

## Description
MCP server for Alpha Vantage: stock quotes, forex, crypto. Needs a free API key. Published from a private commercial monorepo. Not affiliated with or endorsed by Alphavantage.

## Setup Requirements
- `ALPHAVANTAGE_API_KEY` (required): set in your MCP client config before use.

## Category
Finance

## Features

- Stock quote: Quote with open/high/low, change, volume. Free tier is 25 calls/day.
- FX rate: Currency exchange rate between two codes.
- Crypto price: Crypto price in a market currency.
- Symbol search: Find ticker symbols by company name, e.g. ibm.
