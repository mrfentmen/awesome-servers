# Etsy MCP

## Tagline
MCP server for Etsy shops and listings. Needs a free Etsy API key.

## Description
MCP server for Etsy shops and listings. Needs a free Etsy API key. Published from a private commercial monorepo. Not affiliated with or endorsed by Etsy.

## Setup Requirements
- `ETSY_API_KEY` (required): set in your MCP client config before use.

## Category
Business Tools

## Features

- Find shop: Find Etsy shops by name: rating, listings count, URL.
- Shop listings: Active listings of an Etsy shop: titles, prices, quantities, links.
- Get listing: One Etsy listing: title, price, quantity, link, image.

## Getting Started

- "Ask your assistant about etsy using this server once installed"
- Tool: find_shop — Find Etsy shops by name: rating, listings count, URL.
- Tool: shop_listings — Active listings of an Etsy shop: titles, prices, quantities, links.
- Tool: get_listing — One Etsy listing: title, price, quantity, link, image.
