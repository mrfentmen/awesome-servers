# novu-mcp

Query Novu (key; set NOVU_API_KEY, ApiKey header; optional NOVU_BASE_URL for EU): subscribers, topics, notifications.

## Tools

- `list_subscribers` — Notification subscribers.
- `get_subscriber` — Subscriber details.
- `list_topics` — Notification topics.
