## Tagline

## Description
MCP server for USAJOBS: federal job search. Needs a free API key. Published from a private commercial monorepo. Not affiliated with or endorsed by Usajobs.

## Setup Requirements
- `USAJOBS_API_KEY` (required): set in your MCP client config before use.
- `USAJOBS_EMAIL` (required): set in your MCP client config before use.

## Category
Business Tools

## Features

- Search federal jobs: US federal jobs by keyword and location, with pay bands and closing dates.
