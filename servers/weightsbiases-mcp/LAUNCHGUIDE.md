# Weightsbiases MCP

## Tagline
MCP server for Weights & Biases: profile, projects, runs. Needs a free API key.

## Description
MCP server for Weights & Biases: profile, projects, runs. Needs a free API key. Published from a private commercial monorepo. Not affiliated with or endorsed by Weightsbiases.

## Setup Requirements
- `WANDB_API_KEY` (required): set in your MCP client config before use.

## Category
Business Tools

## Features

- My profile: The W&B user the API key belongs to.
- List projects: ML projects of a user or team.
- List runs: Recent training runs of a project with states.

## Getting Started

- "Ask your assistant about weightsbiases using this server once installed"
- Tool: my_profile — The W&B user the API key belongs to.
- Tool: list_projects — ML projects of a user or team.
- Tool: list_runs — Recent training runs of a project with states.
