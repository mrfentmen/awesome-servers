# ohdear-mcp

Oh Dear API: monitors with checks and statuses, single monitor lookup. Needs token.

## Setup

```bash
export OHDEAR_API_TOKEN=...
```

## Tools

- `list_monitors` — All Oh Dear monitors with checks and current statuses.
- `get_monitor` — One Oh Dear monitor with full check details.
- `get_monitor_by_url` — Find an Oh Dear monitor by its exact URL.

Part of [awesome-mcps](https://github.com/mrfentmen/awesome-mcps).
