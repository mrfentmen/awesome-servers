## Description
Oh Dear API: monitors with checks and statuses, single monitor lookup. Needs token. Published from a private commercial monorepo. Not affiliated with or endorsed by Ohdear.

## Setup Requirements
- `OHDEAR_API_TOKEN` (required): set in your MCP client config before use.

## Category
Business Tools

## Features
- List monitors: All Oh Dear monitors with checks and current statuses.
- Get monitor: One Oh Dear monitor with full check details.
- Find monitor by URL: Find an Oh Dear monitor by its exact URL.

## Getting Started
- "Ask your assistant about ohdear using this server once installed"

- Tool: get_monitor_by_url — Find an Oh Dear monitor by its exact URL.
