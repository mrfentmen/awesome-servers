# Jetbrains MCP

## Tagline
Keyless MCP server for JetBrains Marketplace: plugin search, details, ratings, downloads.

## Description
Keyless MCP server for JetBrains Marketplace: plugin search, details, ratings, downloads. Published from a private commercial monorepo. Not affiliated with or endorsed by Jetbrains.

## Setup Requirements
- No configuration required. Works out of the box with no API keys.

## Category
Business Tools

## Features

- Search plugins: Search JetBrains Marketplace plugins: names, descriptions, downloads, ratings. Sort by relevance, downloads, rating, name or recently updated.
- Get plugin details: One JetBrains plugin: vendor, downloads, rating, description, page link.
- Top plugins: The Marketplace charts: the most-downloaded or highest-rated plugins overall.
- Plugin versions: Recent releases of one plugin, with version strings and release dates.
- Plugin reviews: Read the most recent written reviews of a plugin, with each reviewer's star rating and date, so you can judge real user sentiment.
- Plugin rating breakdown: Show a plugin's review score distribution — how many raters gave each star value and the average — so an agent can tell a strong plugin from a thin one.
