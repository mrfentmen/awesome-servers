# Jetbrains MCP

## Tagline
Keyless MCP server for JetBrains Marketplace: plugin search, details, ratings, downloads.

## Description
Keyless MCP server for JetBrains Marketplace: plugin search, details, ratings, downloads. Published from a private commercial monorepo. Not affiliated with or endorsed by Jetbrains.

## Setup Requirements
- No configuration required. Works out of the box with no API keys.

## Category
Business Tools

## Features
- Search plugins: Search JetBrains Marketplace plugins: names, descriptions, downloads, ratings.
- Get plugin details: One JetBrains plugin: vendor, downloads, rating, description, page link.

## Getting Started
- "Ask your assistant about jetbrains using this server once installed"
- Tool: search_plugins — Search JetBrains Marketplace plugins: names, descriptions, downloads, ratings.
- Tool: get_plugin — One JetBrains plugin: vendor, downloads, rating, description, page link.
