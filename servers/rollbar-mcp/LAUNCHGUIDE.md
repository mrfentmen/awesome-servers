# Rollbar MCP

## Tagline
Rollbar error tracking. Needs a token (ROLLBAR_ACCESS_TOKEN).

## Description
Rollbar error tracking. Needs a token (ROLLBAR_ACCESS_TOKEN). Not affiliated with the vendor.

## Setup Requirements
- API credentials (free tier) or self-hosted URL. See server README.

## Category
Developer Tools

## Features

- List projects: Rollbar projects the token can read.
- List items: Error items in one project, most recent first.
- Get item: One error item by id, with occurrences and stack.

## Getting Started

- "List my projects"
- "Top errors?"
- Tool: list_projects — Rollbar projects the token can read.
- Tool: list_items — Error items in one project, most recent first.
- Tool: get_item — One error item by id, with occurrences and stack.
