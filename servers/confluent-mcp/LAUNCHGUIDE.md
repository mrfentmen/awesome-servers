# Confluent MCP

## Tagline
MCP server for Confluent Cloud: environments, Kafka clusters. Needs an API key.

## Description
MCP server for Confluent Cloud: environments, Kafka clusters. Needs an API key. Published from a private commercial monorepo. Not affiliated with or endorsed by Confluent.

## Setup Requirements
- `CONFLUENT_API_KEY` (required): set in your MCP client config before use.
- `CONFLUENT_API_SECRET` (required): set in your MCP client config before use.

## Category
Business Tools

## Features

- List environments: Confluent Cloud environments with ids and names.
- List Kafka clusters: Kafka clusters in one environment: cloud, region, availability, endpoint.

## Getting Started

- "Ask your assistant about confluent using this server once installed"
- Tool: list_environments — Confluent Cloud environments with ids and names.
- Tool: list_clusters — Kafka clusters in one environment: cloud, region, availability, endpoint.
