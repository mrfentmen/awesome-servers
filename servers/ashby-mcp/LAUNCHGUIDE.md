# Ashby MCP

## Tagline
Keyless MCP server for Ashby job boards: openings, departments, locations.

## Description
Keyless MCP server for Ashby job boards: openings, departments, locations. Published from a private commercial monorepo. Not affiliated with or endorsed by Ashby.

## Setup Requirements
- No configuration required. Works out of the box with no API keys.

## Category
Jobs

## Features

- List jobs: Open roles on an Ashby-powered job board: titles, departments, locations.
- Search jobs: Search every open role on an Ashby job board by title, team or location.
- Job detail: Get one Ashby role by id, including the full plain-text description.
- Departments: List the teams hiring on an Ashby board, ranked by number of open roles.
- Remote jobs: List only the remote roles on an Ashby job board.
- Compensation: List Ashby roles that publish a pay range, with the salary summary for each role.

## Getting Started

- "Ask your assistant about ashby using this server once installed"

- Tool: list_remote_jobs — List only the remote roles on an Ashby job board.
- Tool: compensation — List Ashby roles that publish a pay range, with the salary summary for each role.
