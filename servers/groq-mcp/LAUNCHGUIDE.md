## Description
MCP server for Groq: fast LLM chat, model list. Needs a free API key. Published from a private commercial monorepo. Not affiliated with or endorsed by Groq.

## Setup Requirements
- `GROQ_API_KEY` (required): set in your MCP client config before use.

## Category

## Features
- Chat completion: Ask a Groq-hosted LLM. Fast inference, OpenAI-compatible.
- List models: Available Groq model ids.
