# Geckoterminal MCP

## Tagline
Token data from GeckoTerminal. No key required.

## Description
Token data from GeckoTerminal. No key required. Published from a private commercial monorepo. Not affiliated with or endorsed by Geckoterminal.

## Setup Requirements
- No configuration required. Works out of the box with no API keys.

## Category
Business Tools

## Features

- Token: Token details by address on one network: price, supply, pool.
- Trending: Pools with the most activity on GeckoTerminal right now.
- Networks: Blockchains GeckoTerminal tracks, with a 20-network sample. Full list omitted for size.
- Pool detail: One pool by id with base/quote USD prices and reserves. Get ids from search.
- New pools: Recently listed pools on a network with prices and volumes.
- Pool search: Search pools by text across networks, returns ids for the pool tool.
