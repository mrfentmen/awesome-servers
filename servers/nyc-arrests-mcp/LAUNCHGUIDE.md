# NYC Arrests MCP

## Tagline
NYPD arrest records by date, borough and offense. Keyless.

## Description
Search NYPD arrests across year-to-date and historic data. No names in public data — filter by time, place, offense and demographics. Not affiliated with NYPD.

## Setup Requirements
- None. Optional NYC_APP_TOKEN for higher Socrata limits.

## Category
Business Tools

## Features
- search_arrests: Filtered arrest search
- arrest_details: One record
- historic_search: 2006-2023 archive
- top_offenses: Rankings
- precinct_activity: By precinct
- borough_stats: Felony/misd split
- recent_felonies: Latest felonies
- recent_misdemeanors: Latest misdemeanors
- offense_lookup: By penal code
- arrest_map_data: Map points

## Getting Started
- "Assault arrests in Brooklyn this month?"
- "Top offenses in Queens?"
