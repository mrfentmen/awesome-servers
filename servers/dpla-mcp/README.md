# dpla-mcp

Digital Public Library of America: search 50M+ items and collections. Needs free key.

## Setup

```bash
export DPLA_API_KEY=...
```

## Tools

- `search_items` — Search DPLA's millions of photos, books, maps and recordings.
- `get_item` — Full DPLA record with source links and rights info.
- `search_collections` — Search DPLA partner collections and exhibitions.

- `get_collection`
- `title_search`
- `date_search`
- `place_search`
- `sorted_search`
- `facet_search`
