# Simplecast MCP

## Tagline
Simplecast podcast hosting: podcasts, episodes, analytics. Needs API key.

## Description
Simplecast podcast hosting: podcasts, episodes, analytics. Needs API key. Published from a private commercial monorepo. Not affiliated with or endorsed by Simplecast.

## Setup Requirements
- `SIMPLECAST_API_KEY` (required): set in your MCP client config before use.

## Category
Data & Analytics

## Features
- List podcasts: All Simplecast podcasts with ids and titles.
- List episodes: Episodes of a Simplecast podcast with ids, titles, dates.
- Get episode: One Simplecast episode with metadata and audio URL.

## Getting Started
- "Ask your assistant about simplecast using this server once installed"
- Tool: list_podcasts — All Simplecast podcasts with ids and titles.
- Tool: list_episodes — Episodes of a Simplecast podcast with ids, titles, dates.
- Tool: get_episode — One Simplecast episode with metadata and audio URL.
