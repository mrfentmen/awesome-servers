# Simplecast MCP

## Tagline
Search podcasts and analyse any RSS feed - no API key.

## Description
Explore podcasts from your AI assistant: search the Apple Podcasts catalogue for shows and episodes, read country charts, then inspect any RSS feed for latest episodes, episode counts, average length and publishing cadence. No account or key. An independent MCP server. Not affiliated with or endorsed by Simplecast.

## Setup Requirements
No setup. Uses the public Apple Podcasts search and any podcast RSS feed.

## Category
Media

## Features

- Search podcasts: Search the Apple Podcasts catalogue by name or topic and get each show's episode count, genre, Apple id and RSS feed URL. No API key needed.
- Search episodes: Search podcast episode titles across the whole Apple Podcasts catalogue and return the show, date and length of each match.
- Podcast charts: Apple Podcasts top chart for a country, with rank, publisher and genre for every show.
- Podcast details: Look up one show by Apple id or by name and get its publisher, genre, episode count, latest release and a live check of its RSS feed.
- Latest episodes: Read any podcast RSS feed and list its newest episodes with publication date, length and audio URL.
- Podcast stats: Analyse a podcast feed: episode count, first and latest episode, average length, publishing cadence and whether the show is overdue.
- Compare podcasts: Compare two podcast feeds side by side on episode count, latest episode, average length and publishing cadence.
