# simplecast-mcp

Simplecast podcast hosting: podcasts, episodes, analytics. Needs API key.

## Setup

```bash
export SIMPLECAST_API_KEY=...
```

## Tools

- `list_podcasts` — All Simplecast podcasts with ids and titles.
- `list_episodes` — Episodes of a Simplecast podcast with ids, titles, dates.
- `get_episode` — One Simplecast episode with metadata and audio URL.

Part of [awesome-mcps](https://github.com/mrfentmen/awesome-mcps).
