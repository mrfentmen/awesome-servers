# Wayback Machine MCP

## Tagline
Snapshots and archived pages. Keyless.

## Description
MCP server for the Wayback Machine, snapshot history, page availability, and dead site recovery.

## Setup Requirements
- API key as documented in README where required (all free tiers/self-serve).

## Category
Content & Media

## Features
- get_snapshots: Snapshot history
- get_availability: Closest snapshot
- read_snapshot: Archived page

## Getting Started
- "Earliest snapshot of example.com"
- Tool: get_snapshots — Snapshot history
- Tool: get_availability — Closest snapshot
- Tool: read_snapshot — Archived page
