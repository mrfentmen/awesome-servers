# wayback-mcp

MCP server for the Internet Archive Wayback Machine: closest snapshots, snapshot history for a URL, and archived page retrieval. Keyless.

## Tools

- `get_snapshots` — snapshot history for a URL
- `get_availability` — closest archived snapshot of a URL
- `read_snapshot` — retrieve an archived page
