# sentry-mcp

Query Sentry (auth token; set SENTRY_AUTH_TOKEN, Bearer): organizations, projects, issues.

## Tools

- `list_orgs` — Organizations.
- `org_projects` — Projects in an org.
- `org_issues` — Recent issues (24h).
