# gitlab-mcp

Query GitLab (token; set GITLAB_PRIVATE_TOKEN, PRIVATE-TOKEN header; optional GITLAB_BASE_URL for self-host): profile, projects, groups.

## Tools

- `me` — Authenticated user.
- `list_projects` — My projects.
- `list_groups` — Groups.
