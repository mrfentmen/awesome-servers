# GitLab MCP

## Tagline
Profile, projects, groups. Token.

## Description
Profile, projects, groups. Token. Not affiliated with the vendor.

## Setup Requirements
- API credentials (free tier/sandbox). See server README.

## Category
Developer Tools

## Features
- list_issues: Assigned/open issues.
- list_merge_requests: Open merge requests.
- project_details: Single project.
- project_pipelines: Recent pipelines.
- group_projects: Projects in a group.
- render_markdown: GitLab-flavored HTML.
- public_snippets: Discover snippets.

- My profile: The GitLab user the token belongs to.
- List projects: Projects the token can see, most recent first.
- List groups: Groups the token can see, with path and id.
- Search public: Public projects by query (no token needed).

## Getting Started

- "My projects?"
- Tool: me — The GitLab user the token belongs to.
- Tool: list_projects — Projects the token can see, most recent first.
- Tool: list_groups — Groups the token can see, with path and id.
- Tool: search_public — Public projects by query (no token needed).
