# Rybbit MCP

## Tagline
Rybbit analytics: site overview, users, journeys. Cloud or self-hosted.

## Description
Rybbit analytics: site overview, users, journeys. Cloud or self-hosted. Published from a private commercial monorepo. Not affiliated with or endorsed by Rybbit.

## Setup Requirements
- `RYBBIT_API_KEY` (required): set in your MCP client config before use.
- `RYBBIT_BASE_URL` (required): set in your MCP client config before use.

## Category
Data & Analytics

## Features

- Get site overview: Rybbit sessions, pageviews, users, bounce rate for a site and period.
- List users: Rybbit users for a site with pagination.
- Get journeys: Common Rybbit navigation paths (journeys) through a site.
