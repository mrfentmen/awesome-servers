# Mercury Banking MCP

## Tagline
Mercury accounts and transactions. Needs a sandbox key (MERCURY_API_KEY).

## Description
Mercury accounts and transactions. Needs a sandbox key (MERCURY_API_KEY). Not affiliated with the vendor.

## Setup Requirements
- Vendor API credentials (free tier/sandbox available). See server README.

## Category
Finance

## Features

- List accounts: Mercury accounts with balance and type.
- Get account: One account by id, with routing details.
- List transactions: Transactions on an account, newest first.

## Getting Started

- "List my accounts"
- "Recent transactions?"
- Tool: list_accounts — Mercury accounts with balance and type.
- Tool: get_account — One account by id, with routing details.
- Tool: list_transactions — Transactions on an account, newest first.
