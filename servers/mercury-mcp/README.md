# mercury-mcp

Query the Mercury API (sandbox key; set MERCURY_API_KEY, Bearer): accounts, account details, transactions.

## Tools

- `list_accounts` — Mercury accounts.
- `get_account` — Account details by ID.
- `list_transactions` — Transactions for an account.
