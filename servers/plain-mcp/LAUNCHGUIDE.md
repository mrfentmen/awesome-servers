# Plain Support MCP

## Tagline
Plain customers and support threads. Needs a key (PLAIN_API_KEY).

## Description
Plain customers and support threads. Needs a key (PLAIN_API_KEY). Not affiliated with the vendor.

## Setup Requirements
- Vendor API credentials (free tier/sandbox available). See server README.

## Category
Business Tools

## Features

- List customers: Support customers with email and company.
- List threads: Open support threads, newest first.
- Get thread: One thread by id, with messages and status.

## Getting Started

- "List customers"
- "Open support threads?"
- Tool: list_customers — Support customers with email and company.
- Tool: list_threads — Open support threads, newest first.
- Tool: get_thread — One thread by id, with messages and status.
