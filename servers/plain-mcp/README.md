# plain-mcp

Query the Plain GraphQL API (free tier key; set PLAIN_API_KEY, Bearer): customers, threads, thread details.

## Tools

- `list_customers` — Support customers.
- `list_threads` — Support threads.
- `get_thread` — Thread details by ID.
