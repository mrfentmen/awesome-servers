## Description
PlayCanvas projects: assets, rate limits. Needs token. Published from a private commercial monorepo. Not affiliated with or endorsed by Playcanvas.

## Setup Requirements
- `PLAYCANVAS_ACCESS_TOKEN` (required): set in your MCP client config before use.

## Category
Business Tools

## Features
- List project assets: Assets in a PlayCanvas project branch.
- Get asset: Single PlayCanvas asset metadata.
- Rate limits: Current PlayCanvas REST API rate limits.

## Getting Started
- "Ask your assistant about playcanvas using this server once installed"
- Tool: list_project_assets — Assets in a PlayCanvas project branch.
- Tool: get_asset — Single PlayCanvas asset metadata.
- Tool: get_rate_limits — Current PlayCanvas REST API rate limits.
