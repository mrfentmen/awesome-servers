# spacedevs-mcp

Query TheSpaceDevs Launch Library 2 (keyless): upcoming launches, past launches, launch details.

## Tools

- `upcoming` — Next rocket launches.
- `previous` — Recent past launches.
- `get_launch` — Details by launch ID.
