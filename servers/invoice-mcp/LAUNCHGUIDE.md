# Invoice Manager MCP

## Tagline
Generate, PDF, send and validate invoices. Local-first.

## Description
MCP server for generating, sending, and tracking invoices across carriers (UPS, USPS, FedEx, DHL).

## Setup Requirements
- API key as documented in README where required (all free tiers/self-serve).

## Category
Business Tools

## Features
- generate_invoice: Create invoice
- convert_to_pdf: Invoice to PDF (needs wkhtmltopdf)
- send_invoice: Send via carrier
- validate_address: Address check

## Getting Started
- "Invoice client X for $500"
- Tool: generate_invoice — Create invoice
- Tool: convert_to_pdf — Invoice to PDF (needs wkhtmltopdf)
- Tool: send_invoice — Send via carrier
- Tool: validate_address — Address check
